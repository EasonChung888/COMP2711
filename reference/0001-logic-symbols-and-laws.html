Symbols, tables, and laws.

Use this sheet to recognise notation and choose a legal transformation. Do not memorise it as one long list: first identify the main operator, then find the matching shape.

1 · The basic objects

Proposition

A declarative statement that is either true or false, but not both.

p, q, r, …

Predicate

A statement whose truth depends on one or more variable values.

P(x), R(x, y)

Tautology

True under every assignment of its propositional variables.

p ∨ ¬p ≡ T

Contradiction

False under every assignment of its propositional variables.

p ∧ ¬p ≡ F

Contingency

True under some assignments and false under others.

p → ¬p

Equivalence

Two formulas have the same truth value under every assignment.

A ≡ B iff A ↔ B is a tautology

Operator precedence

¬   before   ∧   before   ∨   before   →   before   ↔

Quantifiers bind their stated scope before the surrounding binary operators. Add parentheses whenever a reader could hesitate.

Fast error check

  • p → q does not mean q → p. Only the contrapositive is guaranteed equivalent.
  • De Morgan changes both the connective and each component's sign.
  • ≡ states equivalence; ↔ is an operator inside a proposition.
  • To disprove a tautology or equivalence, one truth assignment is enough.
