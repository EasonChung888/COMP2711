# COMP2711 Logic Resources

## Knowledge

- [Lecture L01: Propositional Logic](lecture/L01-Logic-Propositional-Logic.pdf)
  Canonical source for propositions, connectives, implication language, truth tables, classification, and equivalence laws. Use pages 3-36 for Day 1.
- [Lecture L02: Predicate Logic](lecture/L02-Logic-Predicate-Logic.pdf)
  Canonical source for predicates, domains, quantifiers, restricted domains, scope, equivalence, negation, and nesting. Use pages 1-49 for Lessons 7-10.
- [Lecture L03: Inference and Proofs](lecture/L03-Logic-Inference.pdf)
  Canonical source for eight propositional inference rules, four predicate rules, and the four core proof structures. Use pages 1-42 for Lessons 11-13.
