矩阵乘法中，要做多少次普通乘法？

这页用矩阵乘法说明怎样数算法的操作次数。图中的矩阵是：

A=(2510),B=(611242).A=\begin{pmatrix}2&5\\1&0\end{pmatrix},\qquad B=\begin{pmatrix}6&1&1\\2&4&2\end{pmatrix}.A=(21​50​),B=(62​14​12​).

矩阵相乘时，结果的第 iii 行、第 jjj 列元素，来自 AAA 的第 iii 行和 BBB 的第 jjj 列对应相乘再相加。

例如图上用颜色标出的左上角元素是：

c11=2×6+5×2=12+10=22.c_{11}=2\times6+5\times2=12+10=22.c11​=2×6+5×2=12+10=22.

同样，第一行的另外两个元素是 2×1+5×4=222\times1+5\times4=222×1+5×4=22、2×1+5×2=122\times1+5\times2=122×1+5×2=12。第二行由 (1,0)(1,0)(1,0) 分别和三列计算，得到 6,1,16,1,16,1,1。因此：

AB=(222212611).AB=\begin{pmatrix}22&22&12\\6&1&1\end{pmatrix}.AB=(226​221​121​).

题目问的是 scalar multiplications（标量乘法），也就是普通数字之间的乘法，不是整个矩阵相乘算一次。

一般地，AAA 是 m×nm\times nm×n，BBB 是 n×pn\times pn×p，结果 CCC 是 m×pm\times pm×p。标准逐项算法要计算 mpmpmp 个结果元素，每个元素需要 nnn 次标量乘法：

cij=∑k=1naikbkj.c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}.cij​=k=1∑n​aik​bkj​.

因此总乘法次数为 mp×n=mnpmp\times n=mnpmp×n=mnp。本页例子对应 m=2,n=2,p=3m=2,n=2,p=3m=2,n=2,p=3，于是有 2×2×3=122\times2\times3=122×2×3=12 次乘法。这是在按标准算法计数，包含乘以 0 的步骤；如果额外利用特定矩阵中的零来优化，实际执行次数可能减少。

数三层循环中的乘法次数

这段伪代码的核心操作是：

s = s + A[i, k] × B[k, j]

每执行一次这一行，就做一次标量乘法。要数总乘法次数，只需数这一行执行了多少次。

按本页写出的循环范围，iii 从 1 到 mmm，jjj 从 1 到 nnn，kkk 从 1 到 ppp。所以可以把每次乘法用唯一的三元组 (i,j,k)(i,j,k)(i,j,k) 标记。

  • 选择 iii，有 mmm 种可能。
  • 对每个 iii，选择 jjj，有 nnn 种可能。
  • 对每个 (i,j)(i,j)(i,j)，选择 kkk，有 ppp 种可能。

由乘法法则，执行次数为：

m×n×p=mnp.m\times n\times p=mnp.m×n×p=mnp.

变量 sss 是累加器。对于每一对 (i,j)(i,j)(i,j)，先令 s=0s=0s=0，然后把所有 A[i,k]B[k,j]A[i,k]B[k,j]A[i,k]B[k,j] 加进去，最后令 C[i,j]=sC[i,j]=sC[i,j]=s。因此赋值 C[i,j]=sC[i,j]=sC[i,j]=s 应在最内层 kkk 循环完成之后执行。本页用缩进表达这一点，最内层的结束标记没有完整写出，可以读成：

for i = 1 to m
    for j = 1 to n
        s = 0
        for k = 1 to p
            s = s + A[i, k] × B[k, j]
        end for
        C[i, j] = s
    end for
end for

还要留意课件的记号：上一页用 A:m×nA:m\times nA:m×n、B:n×pB:n\times pB:n×p；本页的循环则对应 A:m×pA:m\times pA:m×p、B:p×nB:p\times nB:p×n。也就是 nnn 和 ppp 的角色交换了。若要沿用上一页的矩阵维度，应让 jjj 跑到 ppp、kkk 跑到 nnn。两种记号下总次数都是 mnpmnpmnp，但写程序时维度必须一致。

从最内层向外计算循环总次数

这一页把 mnpmnpmnp 的来源分层解释。最方便的方法是先固定外层变量，只观察最内层，再逐层扩大计算范围。

先固定 iii 和 jjj。 此时 kkk 从 1 跑到 ppp，每次做一次乘法，所以这一轮最内层循环做 ppp 次乘法。课件说“固定 jjj”时，外面的 iii 也处于某个固定值。

再固定 iii，让 jjj 跑完。 jjj 有 nnn 个不同值。每取一个新的 jjj，都要重新执行一次完整的 kkk 循环，因此这一层总计：

p+p+⋯+p⏟n 项=np.\underbrace{p+p+\cdots+p}_{n\text{ 项}}=np.n 项p+p+⋯+p​​=np.

最后让 iii 跑完。 iii 有 mmm 个值，每个值都要完成刚才那组 npnpnp 次乘法，所以总计：

np+np+⋯+np⏟m 项=mnp.\underbrace{np+np+\cdots+np}_{m\text{ 项}}=mnp.m 项np+np+⋯+np​​=mnp.

例如取 m=2,n=3,p=4m=2,n=3,p=4m=2,n=3,p=4：每一对 (i,j)(i,j)(i,j) 需要 4 次乘法；每个 iii 对应 3 个 jjj，需要 12 次；两个 iii 共需要 24 次。

要区分“进入一次最内层循环”和“最内层循环体执行一次”。在整个算法中，完整的 kkk 循环启动了 mnmnmn 次，每次循环体执行 ppp 次，所以红色乘法语句执行 mnpmnpmnp 次。

这种直接相乘依赖于各层循环范围固定。如果某层循环的上界取决于外层变量，例如 j=1,…,ij=1,\ldots,ij=1,…,i，每一轮的次数就不相同，应先写出求和，不能直接把最大上界相乘。

内层循环长度变化时，要把各轮次数相加

这段排序程序依次把位置 iii 与后面的位置比较。如果 A[i]>A[j]A[i]>A[j]A[i]>A[j]，就交换这两个元素。题目只问第 (3) 行的元素比较执行次数，并不是问交换次数。

外层 iii 从 1 到 n−1n-1n−1，内层 jjj 从 i+1i+1i+1 到 nnn。固定 iii 时，jjj 的取值数量为：

n−(i+1)+1=n−i.n-(i+1)+1=n-i.n−(i+1)+1=n−i.

因此：当 i=1i=1i=1，要比较 n−1n-1n−1 次；当 i=2i=2i=2，要比较 n−2n-2n−2 次；一直到 i=n−1i=n-1i=n−1，只比较 1 次。

不同外层轮次包含不同的比较执行，我们把这些轮次相加：

∑i=1n−1(n−i)=(n−1)+(n−2)+⋯+1=n(n−1)2.\sum_{i=1}^{n-1}(n-i)=(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}2.i=1∑n−1​(n−i)=(n−1)+(n−2)+⋯+1=2n(n−1)​.

例如 n=4n=4n=4 时，要比较的位置对依次是 (1,2),(1,3),(1,4),(2,3),(2,4),(3,4)(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)，共 3+2+1=63+2+1=63+2+1=6 次。也可以理解成：每一对不同位置恰好比较一次。

比较条件成立或不成立，都必须先执行比较才能知道。因此，即使数组已经排好序，第 (3) 行仍然执行相同次数；但第 (4) 行是否交换取决于数组内容，不能把这两个次数混为一谈。

课件称其为 selection sort。这个版本一旦发现更小值就立即交换，与常见“先记录最小位置、每轮最后只交换一次”的写法有所不同，不过这里所数的元素比较次数同样为 n(n−1)/2n(n-1)/2n(n−1)/2，随 nnn 的增长为二次量级。

排序的第一轮：把最小值留在第一个位置

这一页只看外层循环的第一轮，即 i=1i=1i=1。内层变量 jjj 从 2 到 nnn，所以位置 1 要依次和后面的每个位置比较。

图中的小方格标的是数组位置，不是数组里存放的数值。浅蓝色弧线从位置 1 连到位置 2、3，直到位置 nnn；每条线代表一次比较，一共有 n−1n-1n−1 条。

当发现 A[j]A[j]A[j] 比当前 A[1]A[1]A[1] 更小时，就交换两者，使较小的值留在 A[1]A[1]A[1]。所以扫描到哪里，A[1]A[1]A[1] 就保存到目前为止看见的最小值。

例如开始时数组是 [5,3,4,1][5,3,4,1][5,3,4,1]：

  1. 比较 5 和 3，交换后得到 [3,5,4,1][3,5,4,1][3,5,4,1]。
  2. 比较当前位置 1 的 3 和位置 3 的 4，不交换。
  3. 比较 3 和位置 4 的 1，交换后得到 [1,5,4,3][1,5,4,3][1,5,4,3]。

第一轮结束后，最小值 1 已经在位置 1；后面的部分还不一定排好。

无论具体数据怎样，这一轮都必须检查位置 2,3,…,n2,3,\ldots,n2,3,…,n，比较次数固定为：

n−2+1=n−1.n-2+1=n-1.n−2+1=n−1.

例子中比较了 3 次，只交换了 2 次。课件右侧的 n−1n-1n−1 数的是比较，而非交换。理解“每条弧线就是一次比较”，就能把程序循环与图上的计数对应起来。

排序的第二轮：只检查尚未排好的部分

这一页看 i=2i=2i=2 时发生什么。第一轮已经把整个数组的最小元素放在 A[1]A[1]A[1]，所以第二轮可以让位置 1 保持不动，只处理 A[2],…,A[n]A[2],\ldots,A[n]A[2],…,A[n]。

内层 jjj 从 3 到 nnn。每次拿 A[2]A[2]A[2] 与 A[j]A[j]A[j] 比较，发现更小值就交换，把已检查部分中的最小值保留在 A[2]A[2]A[2]。本轮结束后，A[2]A[2]A[2] 就是剩余部分的最小元素，也就是整个数组按非降序排列后的第二个元素。

例如上一轮结束后的数组为 [1,5,4,3][1,5,4,3][1,5,4,3]：先比较 5 和 4，变成 [1,4,5,3][1,4,5,3][1,4,5,3]；再比较 4 和 3，变成 [1,3,5,4][1,3,5,4][1,3,5,4]。前两个位置已经正确，后面仍可继续排序。

图中弧线从位置 2 连到位置 3、4，直到位置 nnn。这次没有连回位置 1，因为那个位置已经处理完成。弧线数量，也就是比较次数，为：

n−3+1=n−2.n-3+1=n-2.n−3+1=n−2.

与第一轮的 n−1n-1n−1 次相比，第二轮少一次。这展示出一个规律：每一轮确定一个位置，下一轮需要检查的范围便减少一个元素。

如果数组存在重复值，“第二小”应理解为排序后的第二个元素，允许它与最小值相等。例如 [1,1,3][1,1,3][1,1,3] 的前两个值都是 1。这不影响每轮的比较次数，也不影响按非降序排序的结论。

最后一轮与总比较次数

当外层变量到达 i=n−1i=n-1i=n−1，只剩下最后两个位置需要确定顺序。内层变量 jjj 从 nnn 到 nnn，所以恰好执行一次，不是零次。

比较 A[n−1]A[n-1]A[n−1] 和 A[n]A[n]A[n]，必要时交换，便让较小的值在倒数第二个位置，较大的值在最后。前面的 n−2n-2n−2 个位置已经排好，因此整段排序完成。

各轮比较次数依次为：

n−1,n−2,…,2,1.n-1,\quad n-2,\quad\ldots,\quad2,\quad1.n−1,n−2,…,2,1.

这些轮次的执行互不重叠，所以用加法法则求总数：

T=(n−1)+(n−2)+⋯+1.T=(n-1)+(n-2)+\cdots+1.T=(n−1)+(n−2)+⋯+1.

把同一个和倒过来写，与原式逐项相加，每一列都等于 nnn，而这样的列有 n−1n-1n−1 个，因此 2T=n(n−1)2T=n(n-1)2T=n(n−1)，得到：

T=n(n−1)2.T=\frac{n(n-1)}2.T=2n(n−1)​.

例如 5 个元素需要 4+3+2+1=104+3+2+1=104+3+2+1=10 次元素比较。也可从位置对来看：每次比较对应一个 1≤i<j≤n1\leq i<j\leq n1≤i<j≤n 的位置对，而这样的对有 (n2)=n(n−1)/2\binom n2=n(n-1)/2(2n​)=n(n−1)/2 个。

这个数量描述的是给定伪代码第 (3) 行的比较次数，不包含循环边界判断，也不是交换总次数。它解释了该算法为何具有二次规模的比较工作量：当输入长度很大时，主导项是 n2/2n^2/2n2/2。

练习 1 · 2018 Final 10(c)

原题 PDF · 第 14 页

Given a n×pn\times pn×p matrix AAA and a p×mp\times mp×m matrix BBB, the following algorithm computes the n×mn\times mn×m product matrix C=A⋅BC=A\cdot BC=A⋅B.

Matrix-Mult(A,B)

for i = 1 to n do
    for j = 1 to m do
        C[i,j] = 0
        for k = 1 to p do
            C[i,j] = C[i,j] + A[i,k] · B[k,j]
        end for
    end for
end for
return C

c) Express the total number of multiplications that the algorithm does, expressed as a function of n,m,pn,m,pn,m,p.

查看答案与解析

Provenance: official; supplied source conclusion checked on PDF page(s) 15. The Chinese derivation expands the reasoning.

Answer. nmpnmpnmp.

Derivation/proof. For each of nnn rows and mmm columns, the algorithm runs the inner loop ppp times. Every inner iteration contains exactly one scalar multiplication A[i,k]B[k,j]A[i,k]B[k,j]A[i,k]B[k,j]. Hence the exact multiplication count is n⋅m⋅pn\cdot m\cdot pn⋅m⋅p. Initializing to zero and adding do not contribute to the requested multiplication count.

中文解答

推导。 外层遍历 nnn 行，中层遍历 mmm 列，所以共 nmnmnm 个输出元素。每个输出的内层执行 ppp 次，每次恰乘一次 A[i,k]⋅B[k,j]A[i,k]\cdot B[k,j]A[i,k]⋅B[k,j]。因此精确乘法数 nm⋅p=nmpnm\cdot p=nmpnm⋅p=nmp。清零和加法不计入所问乘法次数，所以没有额外常数项。

容易出错的地方

  • 把加法一起计入乘法数量。
  • 把维度 p 与输出列数 m 混淆。
