# 为什么计算机科学需要计数？

这页说明：计数不仅是“数出有几个”，它帮助我们判断程序需要多少资源、事件发生的机会有多大，以及一种编码能容纳多少对象。

**第一种应用是算法的时间或空间复杂度。** 例如，一个循环执行 $n$ 次，每次做固定数量的操作，工作量就与 $n$ 成正比。如果有两层循环，每一层都执行 $n$ 次，内层操作总共执行 $n\times n=n^2$ 次。这里数的是“操作发生了多少次”。空间分析也类似，可以数需要保存多少个数据项。

**第二种应用是计算概率。** 在所有基本结果等可能时，事件的概率可以写成：

$$P(E)=\frac{\text{事件 }E\text{ 包含的结果数}}{\text{全部可能结果数}}.$$

所以先数清分子和分母，才能算出概率。等可能这个条件很重要：如果不同结果的概率不相等，就不能只靠结果数量相除。

**第三种应用是检查编码容量，例如 IP 地址。** 若某种编号用 $b$ 个二进制位表示，每一位有 0、1 两种选择，那么有 $2^b$ 种位串。实际可用地址数还要考虑协议保留值等限制；本页只是说明“先计算总容量，再和需求比较”的思路。

页末给了两组同义名称：

- **Product rule = sequential rule**：乘法法则，也叫顺序法则。关键词是完成任务所需的多个步骤。
- **Sum rule = disjunctive rule**：加法法则，也叫析取法则。关键词是互不重叠的不同选择类别。

同一个问题可以同时用两种法则：先分类，在每类中分步骤计数，最后把各类的数量加起来。
