# 如何读乘法逆元表？

$a$ 模 $m$ 的乘法逆元是满足 $ab\equiv1\pmod m$ 的整数 $b$，常记为 $a^{-1}$，此处默认 $m\ge2$。这不是普通实数倒数 $1/a$，而是相乘后余数为 $1$ 的整数代表。

本页四张表如下，横向顺序对应 $a=1,2,\ldots,m-1$；“无”表示不存在逆元。

| 模数 | 依次对应的逆元 |
| --- | --- |
| $5$ | $1,3,2,4$ |
| $7$ | $1,4,5,2,3,6$ |
| $6$ | $1,\text{无},\text{无},\text{无},5$ |
| $8$ | $1,\text{无},3,\text{无},5,\text{无},7$ |

例如模 $5$ 时 $2\cdot3=6\equiv1$，所以 $2,3$ 互为逆元。模 $8$ 时 $3^2=9$、$5^2=25$、$7^2=49$，都余 $1$，因此这三个数各自是自己的逆元。

表中 $5,7$ 为素数时所有非零元素都有逆元，$6,8$ 为合数时则有缺项。真正需要判断的关系是元素与模数是否互素，而不是元素本身是否为素数。例如 $4$ 在模 $7$ 时有逆元 $2$，虽然 $4$ 是合数。
