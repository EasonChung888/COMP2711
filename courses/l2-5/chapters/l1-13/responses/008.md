# 用 500 ml 与 700 ml 容器量出 100 ml

两个无刻度容器容量为 $500,700$ ml，可以装满、倒空、互相倒水，水源无限。目标是准确得到 $100$ ml。

右图操作可按数对“500 ml 容器内水量，700 ml 容器内水量”记录：先将小容器装满并倒入大容器，得到 $(0,500)$；再装满小容器，把大容器补满，得到 $(300,700)$。倒空大容器，再把小容器剩余水倒进去，得到 $(0,300)$；再次装满小容器并倒入大容器直至大容器满，最后得到 $(100,700)$。

这相当于装了三次 $500$ ml、减去两份 $700$ ml：

$$3\cdot500-2\cdot700=100=\gcd(500,700).$$

负系数代表移去或倒掉的水量，不是出现“负的水”。

课件最后说 GCD 的倍数都可获得，需要结合容器容量与目标方式理解：所有可测的水量必须是 $100$ 的倍数，但若要求最终放在某一个容器内，就还不能超过该容器容量；若要求更大总量，需要允许额外收集或累计。整数线性组合说明可达性背后的算术结构，实际操作仍要遵守容量限制。
