用两个数的整数倍拼出 GCD

6,146,146,14 的最大公约数是 222，而

2=(−2)⋅6+1⋅14.2=(-2)\cdot6+1\cdot14.2=(−2)⋅6+1⋅14.

这里系数 −2-2−2 必不可少；若只许非负系数，就无法用 6,146,146,14 组成正数 222。

Bézout’s Theorem（贝祖定理）说，对任意正整数 a,ba,ba,b，总存在整数 s,ts,ts,t 使

gcd⁡(a,b)=sa+tb.\gcd(a,b)=sa+tb.gcd(a,b)=sa+tb.

此前只知道公约数整除每个整数线性组合，现在还保证某个组合恰好等于 GCD。

存在这样的系数，不表示系数唯一。若 d=gcd⁡(a,b)=sa+tbd=\gcd(a,b)=sa+tbd=gcd(a,b)=sa+tb，则对任意整数 kkk，改用 s+k(b/d)s+k(b/d)s+k(b/d) 与 t−k(a/d)t-k(a/d)t−k(a/d)，增加的两项相互抵消，仍得到 ddd。

系数也能算出来。欧几里得算法的每个余数都是前两数的整数线性组合，将关系反向代回，就把最后的 GCD 写成最初两个输入的组合。课件用这个构造算法来说明定理。

扩展欧几里得算法：从余数反向代回

题目要求把 gcd⁡(252,198)\gcd(252,198)gcd(252,198) 写成 252,198252,198252,198 的整数线性组合。先正常求 GCD：

252=198+54,198=3⋅54+36,252=198+54,\quad198=3\cdot54+36,252=198+54,198=3⋅54+36,

54=36+18,36=2⋅18.54=36+18,\quad36=2\cdot18.54=36+18,36=2⋅18.

最后一个非零余数为 181818，所以 GCD 是 181818。要找系数，从产生 181818 的等式开始向前代入：

18=54−36=54−(198−3⋅54)=4⋅54−198.18=54-36=54-(198-3\cdot54)=4\cdot54-198.18=54−36=54−(198−3⋅54)=4⋅54−198.

接着用 54=252−19854=252-19854=252−198 消去中间余数：

18=4(252−198)−198=4⋅252−5⋅198.18=4(252-198)-198=4\cdot252-5\cdot198.18=4(252−198)−198=4⋅252−5⋅198.

所以一组 Bézout 系数为 s=4,t=−5s=4,t=-5s=4,t=−5。验算 1008−990=181008-990=181008−990=18，确认结果正确。

“扩展”指不仅返回 GCD，还保留能表达它的系数。操作时每轮应消去较晚出现的余数，直到只剩原始两数；不能把中间的 54,3654,3654,36 留在最终答案里，也不要从余数为零的末式误把 GCD 当作零。

用 500 ml 与 700 ml 容器量出 100 ml

两个无刻度容器容量为 500,700500,700500,700 ml，可以装满、倒空、互相倒水，水源无限。目标是准确得到 100100100 ml。

右图操作可按数对“500 ml 容器内水量，700 ml 容器内水量”记录：先将小容器装满并倒入大容器，得到 (0,500)(0,500)(0,500)；再装满小容器，把大容器补满，得到 (300,700)(300,700)(300,700)。倒空大容器，再把小容器剩余水倒进去，得到 (0,300)(0,300)(0,300)；再次装满小容器并倒入大容器直至大容器满，最后得到 (100,700)(100,700)(100,700)。

这相当于装了三次 500500500 ml、减去两份 700700700 ml：

3⋅500−2⋅700=100=gcd⁡(500,700).3\cdot500-2\cdot700=100=\gcd(500,700).3⋅500−2⋅700=100=gcd(500,700).

负系数代表移去或倒掉的水量，不是出现“负的水”。

课件最后说 GCD 的倍数都可获得，需要结合容器容量与目标方式理解：所有可测的水量必须是 100100100 的倍数，但若要求最终放在某一个容器内，就还不能超过该容器容量；若要求更大总量，需要允许额外收集或累计。整数线性组合说明可达性背后的算术结构，实际操作仍要遵守容量限制。

从最大公约数转向乘法逆元

本页把 Multiplicative Inverses（乘法逆元）标为蓝色，表示开始把 GCD 与模运算连接起来。

上一章已经看到，模 444 时 333 有逆元，222 没有；这一章刚建立的工具是 Bézout 定理：GCD 可以写成两个输入的整数线性组合。接下来要研究的正是，这种线性组合何时能给出模 mmm 下乘积为 111 的元素。

学习时要同时保留两个层次：普通整数等式用于构造和证明，同余关系用于在指定模数下解读结果。目录后面仍是线性同余方程与中国剩余定理，本页只是进入它们之前所需的逆元工具。

10 分 · Q-2020-MID-P08 · 原题 PDF · 第 4 页

Show that gcd⁡(21n+4,14n+3)=1\gcd(21n+4,14n+3)=1gcd(21n+4,14n+3)=1, for any n∈Nn\in\mathbb Nn∈N.

查看答案与解析

Official Answer

Source: physical PDF page 4.

Using the Euclid's algorithm, we have gcd⁡(21n+4,14n+3)=gcd⁡(14n+3,7n+1)=gcd⁡(7n+1,1)=1\gcd(21n+4,14n+3)=\gcd(14n+3,7n+1)=\gcd(7n+1,1)=1gcd(21n+4,14n+3)=gcd(14n+3,7n+1)=gcd(7n+1,1)=1.

Supplementary Explanation

Answer. The gcd equals 1 for every permitted n.

Derivation/proof. Subtract the second argument from the first: (21n+4)−(14n+3)=7n+1(21n+4)-(14n+3)=7n+1(21n+4)−(14n+3)=7n+1. Subtract twice this remainder from the second: (14n+3)−2(7n+1)=1(14n+3)-2(7n+1)=1(14n+3)−2(7n+1)=1. Any common divisor therefore divides 1, so it is 1. Equivalently 3(14n+3)−2(21n+4)=13(14n+3)-2(21n+4)=13(14n+3)−2(21n+4)=1 is a Bezout certificate valid for every integer n, including the requested naturals.

The independent Bezout certificate is 3(14n+3)−2(21n+4)=13(14n+3)-2(21n+4)=13(14n+3)−2(21n+4)=1, also valid at n=0n=0n=0.

The Euclidean reductions end in gcd⁡(7n+1,1)=1\gcd(7n+1,1)=1gcd(7n+1,1)=1. This final gcd is one for every allowed nnn, so no exceptional natural-number case remains.

Official Answer

Source: physical PDF page 7.

Since y,zy,zy,z are relatively prime, gcd⁡(y,z)=1\gcd(y,z)=1gcd(y,z)=1. Using the extended Euclidean algorithm, we can calculate integers s,ts,ts,t such that

sy+tz=1(1)sy+tz=1\tag{1}sy+tz=1(1)

Multiplying both sides of (1) with xxx, we get

syx+tzx=x(2)syx+tzx=x\tag{2}syx+tzx=x(2)

We know that from this it follows that zzz divides their sum, that is, z∣(syx+tzx)z\mid(syx+tzx)z∣(syx+tzx). But, from (2), (syx+tzx)=x(syx+tzx)=x(syx+tzx)=x, therefore z∣xz\mid xz∣x.
