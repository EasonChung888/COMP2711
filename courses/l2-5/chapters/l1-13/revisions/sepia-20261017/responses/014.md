# 101 模 4620 的逆元是怎样算出的

先连续取余，确认两数互素：

$$4620=45\cdot101+75,\quad101=75+26,$$
$$75=2\cdot26+23,\quad26=23+3,$$
$$23=7\cdot3+2,\quad3=2+1,\quad2=2\cdot1.$$

最后非零余数为 $1$，故可求逆元。从 $1=3-2$ 往回替换：

$$1=3-(23-7\cdot3)=8\cdot3-23,$$
$$1=8(26-23)-23=8\cdot26-9\cdot23,$$
$$1=8\cdot26-9(75-2\cdot26)=26\cdot26-9\cdot75.$$

这里 $26\cdot26$ 的前一个数是系数，后一个数是余数，数值相同只是巧合。继续消去 $26$ 与 $75$：

$$1=26(101-75)-9\cdot75=26\cdot101-35\cdot75,$$
$$1=26\cdot101-35(4620-45\cdot101)=1601\cdot101-35\cdot4620.$$

读出 $101$ 的系数 $1601$，它已经在 $0$ 至 $4619$ 内，所以标准逆元为 $1601$。乘回有 $101\cdot1601=161701=35\cdot4620+1$。计算只用带余除法和回代，无需分解 $4620$ 的素因子。
