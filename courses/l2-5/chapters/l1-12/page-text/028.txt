 Hashing Strings

 Each character is an integer between 0 and 255
 Need to take all characters into account
 A commonly used hash function
  Suppose characters of a 𝑠       are accessed as 𝑠    0 ,𝑠 1 ,…
   ℎ 𝑠  =     𝑠 0  ⋅31 + 𝑠  1  ⋅ 31 + 𝑠 2   ⋅31  + ⋯    mod  𝑛
 Hash function in Java string library (note that
  overflows are equivalent to modular arithmetic)
  int  h(String s, int     n) {
      int  hash = 0;
      for (int   i = 0; i   < s.length(); i++)
         hash = ((31    * hash) + s[i]);
      return hash % n;
  }
