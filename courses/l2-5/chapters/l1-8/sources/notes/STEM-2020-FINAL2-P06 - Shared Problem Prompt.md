# STEM-2020-FINAL2-P06 - Shared Problem Prompt

## Shared printed wording

Consider the permutations of the 10 digits (0–9). We denote a permutation as $A$, whose elements are $A[0],A[1],\ldots,A[9]$. Calculate the number of permutations that satisfy each of the following conditions:

(a) There is exactly one $i$ such that $A[i]=i$.
(b) There are exactly nine $i$’s such that $A[i]=i$.
(c) $A[0]=1,A[1]=0$.
(d) $A[4]=4,A[5]=5$.

You can express your answers using binomial coefficients, factorials, and $D_n$ (derangement number). However, you should not have summation $\sum$ in your final answers.
