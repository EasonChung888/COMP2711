# 完整三角形与相邻两项求和

本页展示从 $n=0$ 到 $n=8$ 的完整帕斯卡三角形。数值行依次为：

- $n=0$：1。
- $n=1$：1、1。
- $n=2$：1、2、1。
- $n=3$：1、3、3、1。
- $n=4$：1、4、6、4、1。
- $n=5$：1、5、10、10、5、1。
- $n=6$：1、6、15、20、15、6、1。
- $n=7$：1、7、21、35、35、21、7、1。
- $n=8$：1、8、28、56、70、56、28、8、1。

蓝色标出一个具体递推：
$$\binom64+\binom65=\binom75,\qquad15+6=21.$$
它们位于上一行的相邻位置，下方的 21 就是两者之和。

三角形左右对称来自组合数补集对称性；每行合计 $2^n$ 来自全部子集计数；第 $n$ 行正是 $(x+y)^n$ 的系数。

使用图时先确认行号从 0 开始，再按列号 $k=0,\ldots,n$ 找对应值。例如第 8 行中心值为 $\binom84=70$，表示八个元素中选四个的方式数。
