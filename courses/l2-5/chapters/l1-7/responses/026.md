# 第 n=3 行：1、3、3、1

本页数值三角形补入第 3 行的两个 3，与左侧 $\binom31,\binom32$ 对应。上一行是 $1,2,1$，所以新行的内部值分别为 $1+2=3$ 与 $2+1=3$，两端仍为 1。

完整这一行为
$$\binom30,\binom31,\binom32,\binom33=1,3,3,1.$$
它既表示三元素集合各大小子集数量，也给出 $(x+y)^3$ 的系数。

两个内部数相同，不是巧合：选一个元素与选两个元素可通过补集一一对应，故 $\binom31=\binom32$。总和 $1+3+3+1=8$ 则是三元素幂集大小 $2^3$。

数值与符号两幅图可以相互核对：符号告诉我们行号、列号，数值告诉我们相应组合数。位置 $k$ 取决于从该行左端开始的零编号，不应将画在第几个位置与下标 $k$ 混淆。

接着继续由这行的相邻和计算下一行内部值，就能得到四次方的系数。
