# 三个括号的选择位置有区别

本页将 $(x+y)^3$ 明确写成三个 $(x+y)$ 相乘，并用不同颜色区分三个括号。颜色没有改变 $x,y$ 的值，而是帮助追踪每个因子的来源。

展开需要从每个括号各选一项。例如从第一、第二、第三个括号分别取 $x,y,y$，贡献 $xy^2$；分别取 $y,x,y$，也贡献 $xy^2$。选择来源不同，但化简的单项式相同，所以系数要把这些贡献相加。

三个括号各有两个选择，全部选择列表共有 $2^3=8$ 个。按所取 $y$ 的个数 $j=0,1,2,3$ 分类，分别得到
$$C(3,0),C(3,1),C(3,2),C(3,3)=1,3,3,1.$$
每一类产生 $x^{3-j}y^j$。

要数 $xy^2$，选择两个括号贡献 $y$，剩下括号自动贡献 $x$，因此是 $C(3,2)$。三个括号有位置区别，但选定 $y$ 的两个位置作为集合不需要内部排列。

这一展开观点将“分配律的每次选择”变成计数对象，为二项式定理提供直接证明。
