# 填入第一个内部组合数

本页在边界之间加入第 $n=2$ 行的内部项 $\binom21$。其上方相邻两项是 $\binom10=1$ 与 $\binom11=1$，由帕斯卡恒等式，
$$\binom21=\binom10+\binom11=2.$$
因此这行完整数值为 $1,2,1$。

组合含义是从两元素集合中选一个，有两种选择；二项式含义是 $(x+y)^2$ 中 $xy$ 的系数为 2，分别来自第一括号选 $x$、第二选 $y$，以及相反的选择。

本页左边新增的是组合数符号，右边仍主要显示边界。根据递推计算就知道对应中心值应为 2。

三角形的行号从 0 开始，所以 $n=2$ 是显示出来的第三行。每次向下计算，只依赖上一行，不能把两个同一行数相加后放在该行中。

边界固定为 1、内部取上方两数之和，这两个规则已足以确定之后所有行。
