# 正反面次数为何不独立

独立抛两次公平硬币，$X$ 记录正面次数，$Y$ 记录反面次数。每个结果都满足 $X+Y=2$，所以知道 $X$ 就完全知道 $Y$。

要证明不独立，只需找一组违反定义的取值。$X=2$ 与 $Y=2$ 不可能同时发生，因此

$$p(X=2,Y=2)=0.$$

但各自的边际概率都是 $1/4$，乘积为 $1/16\ne0$。所以两个变量不独立。

进一步看乘积：HH、TT 时 $XY=0$；HT、TH 时 $XY=1$。故

$$E(XY)=1\frac12+0\frac12=\frac12.$$

而 $E(X)=E(Y)=1$，所以 $E(X)E(Y)=1$，确实不等于乘积期望。

另一方面，线性性仍然成立：

$$E(X+Y)=E(2)=2=E(X)+E(Y).$$

这页把三件事放在一起：变量有确定关系，因而不独立；乘积期望不能拆；和的期望仍可拆。各次硬币结果独立，并不保证从同一批结果定义出的正反面总数也独立。
