# Coupon Collector：收齐所有种类需要多久

每盒谷物含一张优惠券，共有 $n$ 种，每盒中各类等可能。通常还假设不同盒子之间独立。问题是收齐全部种类所需开盒数量的期望，而不是能保证收齐的固定数量。

至少要开 $n$ 盒，但 $n$ 盒可能出现重复，远不保证收齐。对 $n>1$，任何有限盒数都仍有重复而未收齐的可能，因此不能把期望当作必然完成时间。

分析的自然办法是按**已收集到的不同种类数**分阶段。已经有 $k$ 种时，下一盒出现新种类的概率为

$$p_k=\frac{n-k}{n}.$$

在这一阶段中，若抽到旧类型，状态仍是 $k$；独立投放下，每次成功概率不变，所以等待下一新种类的次数服从几何分布，期望为 $1/p_k$。

从 0 种开始直到 $n$ 种，把这些阶段等待次数相加，就可以用线性性求总期望，无须列出整个收齐时间分布。

越接近收齐，新类型越少，等待越长：最后只缺一种时，每盒成功概率仅 $1/n$。这解释了“最后几种特别难等”的数学原因。
