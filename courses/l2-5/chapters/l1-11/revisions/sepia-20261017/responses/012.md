# 三次抛币的期望为 1.5

独立抛三次公平硬币，正面次数 $X$ 的取值 $0,1,2,3$ 分别有概率 $1/8,3/8,3/8,1/8$。按取值分组计算：

$$E(X)=0\frac18+1\frac38+2\frac38+3\frac18=\frac{12}{8}=1.5.$$

$X=0$ 的项对期望贡献为 0，但这件事仍有 $1/8$ 的概率，并非不可能发生。

1.5 描述重复进行这组三次抛币时的平均正面次数。单次不能出现一个半正面，也不意味着每两组试验一定合计三个正面。

还可以从对称性核对：0 与 3 的概率相同，1 与 2 的概率也相同，平均落在中心 1.5。若换了概率模型，需要重新确定分布；只知道“正面次数可能是 0 到 3”，还不能得出期望。
