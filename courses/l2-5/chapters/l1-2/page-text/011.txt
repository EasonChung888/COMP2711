Exercise on Predicate Logic

1. Which of the following statements (in which             Z+ stands for the
positive integers and Z stands for all         integers   ) is true and which is
false? Explain why.
a) ∀ z ∈ Z+ (z2 + 6z + 10 > 20)
b) ∀ z ∈ Z, (z2 – z ≥ 0)
c) ∃ z ∈ Z+, (z - z2 > 0)
d) ∃ z ∈ Z, (z2 - z = 6)

a) False, because if z=1, 1 + 6 ·1 + 10 = 17 < 20.
b) True. Consider the following cases:
   1) z < 0: true, because z2 - z ≥ 0 ⇒ z2 ≥ z.            The LHS is positive,
   the RHS is negative.
   2) z = 0: true by substitution 02 - 0 ≥ 0.
   3) z > 0: true, because z2 - z ≥ 0 ⇒ z2 ≥ z, for all z ≥ 1.
c) False because z2 ≥ z, , for all z ≥ 1.
d) True, because for z=3, 32-3=6 (also for z=-2).
