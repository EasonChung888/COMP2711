# 两变量量词总表：成立条件与失败条件

前四页逐行展示了两变量量词表，本页把四行的**何时为真**和**何时为假**完整放在一起。文字层只提取到标题，以下按原图表格整理：

| 形式 | 为真需要什么 | 为假需要什么 |
| --- | --- | --- |
| $\forall x\forall y\,P(x,y)$ | 所有数对都满足 $P$ | 找到一对 $(x,y)$ 不满足 $P$ |
| $\forall x\exists y\,P(x,y)$ | 每个 $x$ 都至少有一个合适的 $y$ | 找到一个 $x$，使任何 $y$ 都不合适 |
| $\exists x\forall y\,P(x,y)$ | 找到一个 $x$，对所有 $y$ 都合适 | 每个 $x$ 都能找到某个使它失败的 $y$ |
| $\exists x\exists y\,P(x,y)$ | 找到至少一对满足 $P$ | 所有数对都不满足 $P$ |

表中的“为假”一列就是对应原式的否定。例如第二行失败时，$\exists x\forall y\neg P(x,y)$ 为真；第三行失败时，$\forall x\exists y\neg P(x,y)$ 为真。两者外形相似，却代表不同的反例要求。

第一行的 $\forall x\forall y$ 与 $\forall y\forall x$ 等价，第四行的 $\exists x\exists y$ 与 $\exists y\exists x$ 也等价。中间两行混合量词时，不能只看“一个全称、一个存在”就当作相同：$\forall x\exists y$ 可以为每个 $x$ 挑不同的 $y$，$\exists x\forall y$ 则需要一个固定 $x$ 应付所有 $y$。

判断一道具体题目时，可以先把公式翻成表中的自然语言，再问“若它失败，要给出怎样的证据”。这样既有助于找反例，也可防止把量词顺序读反。
