# 翻译自然语言：量词在“或”里面还是外面

设论域为所有学生，$P(x)$ 表示“学生 $x$ 学过 C++”，$Q(x)$ 表示“学生 $x$ 学过 Python”。课件把四句话翻成：

| 自然语言 | 逻辑式 |
| --- | --- |
| 每个学生都学过 C++ | $\forall x\,P(x)$ |
| 有些学生学过 C++ | $\exists x\,P(x)$ |
| 每个学生都学过 C++ 或 Python | $\forall x\,(P(x)\lor Q(x))$ |
| 所有学生都学过 C++，或者所有学生都学过 Python | $(\forall x\,P(x))\lor(\forall y\,Q(y))$ |

第三句的“或”在**每个学生的判断内部**：对每位学生单独问，他或她是否学过至少一种语言；不同学生可以选择不同语言。第四句的“或”在两个**完整的全称命题之间**：要么人人都学过 C++，要么人人都学过 Python。右半部分把变量写成 $y$ 只是为了看清作用域；写成 $x$ 也不改变真值。

课件用 Alice 和 Bob 给出两式不等价的反例。假设论域只有二人，Alice 只学过 C++，Bob 只学过 Python。对 Alice，$P$ 真；对 Bob，$Q$ 真，所以每个人的 $P(x)\lor Q(x)$ 都真，第三句为真。但不是每人都学过 C++，也不是每人都学过 Python，第四句的两侧全称命题都假，故第四句为假。

这个例子说明 $\forall x\,(P(x)\lor Q(x))$ **不能随意改成** $(\forall x\,P(x))\lor(\forall x\,Q(x))$。从自然语言写式子时，先判断“每个人可以各自满足哪一项”，还是“全体人统一满足某一项”，再决定括号与量词的位置。
