# 量词顺序决定“谁爱谁”的意思

本页论域是所有人，$\mathrm{Loves}(x,y)$ 表示“$x$ 爱 $y$”，因此**第一个位置是施爱者，第二个位置是被爱者**。对同一关系改变量词次序或改变哪个变量被全称量化，会得到不同的陈述。

| 公式 | 自然语言 |
| --- | --- |
| $\forall x\exists y\,\mathrm{Loves}(x,y)$ | 每个人 $x$ 都爱某个人 $y$；不同的 $x$ 可以爱不同的人。 |
| $\exists y\forall x\,\mathrm{Loves}(x,y)$ | 存在某个人 $y$，所有人都爱这个**同一个** $y$。 |
| $\exists x\forall y\,\mathrm{Loves}(x,y)$ | 存在某个人 $x$，他或她爱所有人。 |
| $\forall y\exists x\,\mathrm{Loves}(x,y)$ | 每个人 $y$ 都被某个人 $x$ 爱；不同的 $y$ 可以由不同的人爱。 |

第一式不保证有一位人人都爱的人，因为每个 $x$ 选出的 $y$ 可以不同；第二式要求先选定一个共同的 $y$，所以条件更强。页上“a single person”强调**同一个对象对所有 $x$ 起作用**，不表示世界上恰好只有一位这样的人。

第三式与第二式也不一样：第三式是“有一个人爱所有人”，第二式是“有一个人被所有人爱”。关系 $\mathrm{Loves}(x,y)$ 不一定对称，所以不能把施爱者和被爱者互换。第四式则是“人人至少被一人爱”，与第一式的“人人至少爱一人”方向相反。

页末给出一个允许的交换：**连续的同类量词**可以互换，例如 $\forall x\forall y\,\mathrm{Loves}(x,y)\equiv\forall y\forall x\,\mathrm{Loves}(x,y)$，两式都检查所有有序对 $(x,y)$。这不意味着混合的 $\forall$ 与 $\exists$ 也能任意交换。
