函数：每个输入恰好一个输出

本页正式定义函数（function）。给定非空集合 A,BA,BA,B，函数 f:A→Bf:A\to Bf:A→B 对 AAA 中的每一个元素 aaa，都指定 BBB 中恰好一个元素 bbb，写作 f(a)=bf(a)=bf(a)=b。课件也把函数称为映射（mapping）或变换（transformation）。

“每一个”要求没有遗漏输入；“恰好一个”要求同一输入不能得到两个不同输出。但不同输入可以得到相同输出。例如 A={1,2}A=\{1,2\}A={1,2}、B={x,y}B=\{x,y\}B={x,y}，指定 f(1)=xf(1)=xf(1)=x、f(2)=xf(2)=xf(2)=x 仍是函数；BBB 的元素 yyy 没被用到也没有问题。相反，若同时指定 f(1)=xf(1)=xf(1)=x 和 f(1)=yf(1)=yf(1)=y 且 x≠yx\ne yx=y，就不满足函数定义。

本页还区分几个名称：

  • 定义域（domain）是输入集合 AAA。
  • 陪域（codomain）是声明输出所落入的集合 BBB。
  • 若 f(a)=bf(a)=bf(a)=b，bbb 是 aaa 的像（image），aaa 是 bbb 的一个原像（preimage）。一个输出可能有多个原像，也可能没有原像。
  • 值域（range）是实际取得的所有输出，记为 f(A)={f(a)∣a∈A}f(A)=\{f(a)\mid a\in A\}f(A)={f(a)∣a∈A}。因此 f(A)⊆Bf(A)\subseteq Bf(A)⊆B，但未必等于 BBB。

以上述 f(1)=f(2)=xf(1)=f(2)=xf(1)=f(2)=x 为例，定义域是 {1,2}\{1,2\}{1,2}，陪域是 {x,y}\{x,y\}{x,y}，值域只有 {x}\{x\}{x}。区分陪域与值域，是后面判断函数是否“满射”的关键。

两个函数例子：末两位与整数平方

例一：截取位串末两位。输入是长度至少为 222 的位串，函数 fff 返回最后两个比特。例如 f(11010)=10f(11010)=10f(11010)=10。定义域是所有长度至少为 222 的位串；课件把陪域设为 {00,01,10,11}\{00,01,10,11\}{00,01,10,11}。这四种结果都能由长度为 222 的输入直接产生，所以值域也正好是 {00,01,10,11}\{00,01,10,11\}{00,01,10,11}。长度为 111 的位串不在定义域内，不能要求函数对它给出“末两位”。

单射：不同输入不能合到同一输出

函数 fff 是单射（injective，或 one-to-one），当且仅当对定义域中的任意 a,ba,ba,b，

f(a)=f(b)⟹a=b. f(a)=f(b)\quad\Longrightarrow\quad a=b. f(a)=f(b)⟹a=b.

这句话的等价理解是：只要 a≠ba\ne ba=b，就必须有 f(a)≠f(b)f(a)\ne f(b)f(a)=f(b)。函数定义本来要求“每个输入恰好一个输出”；单射进一步限制不同输入之间不能撞到同一个输出。课件右边的箭头图中，左侧不同元素的箭头指向右侧不同元素，且右侧有元素 vvv 没有箭头指入；这仍可以是单射，说明单射不要求用完陪域。

例一：f:R→Rf:\mathbb R\to\mathbb Rf:R→R，f(x)=x+1f(x)=x+1f(x)=x+1。若 f(a)=f(b)f(a)=f(b)f(a)=f(b)，则 a+1=b+1a+1=b+1a+1=b+1，两边减去 111 得 a=ba=ba=b，所以它是单射。

例二：f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(x)=x2f(x)=x^2f(x)=x2。取两个不同输入 111 与 −1-1−1，有 f(1)=1=f(−1)f(1)=1=f(-1)f(1)=1=f(−1)，所以它不是单射。否定单射只需找出一对不同输入得到同一输出，不必穷举所有整数。

判断单射要始终看清定义域。平方规则在全体整数上不是单射；若把定义域改成非负整数，便不会再有 aaa 与 −a-a−a 同时出现的撞值情况。但本页第二例的定义域明确是 Z\mathbb ZZ，因此答案是否定的。

单射练习：三个都为真的蕴含式

已知 fff 是单射，即对定义域中的所有 a,ba,ba,b，

f(a)=f(b) ⟹ a=b. f(a)=f(b)\ \Longrightarrow\ a=b. f(a)=f(b) ⟹ a=b.

本页问三个陈述哪些成立，答案是：三个都成立，但理由并不相同。

  1. a≠b⇒f(a)≠f(b)a\ne b\Rightarrow f(a)\ne f(b)a=b⇒f(a)=f(b)。这正是单射定义的逆否命题。若不同输入得到相同输出，就违反单射，所以此式刻画单射本身。
  2. a=b⇒f(a)=f(b)a=b\Rightarrow f(a)=f(b)a=b⇒f(a)=f(b)。相同的输入代入同一个已定义函数，自然得到相同输出。这对任何函数都成立，无须额外假设单射。
  3. f(a)≠f(b)⇒a≠bf(a)\ne f(b)\Rightarrow a\ne bf(a)=f(b)⇒a=b。这是第 2 式的逆否命题，同样对任何函数都成立；若 a=ba=ba=b，输出就不能不同。

第 1 式与第 3 式看起来相似，但方向不同。第 1 式说“不同输入必须给出不同输出”，是单射的特殊要求；第 3 式说“不同输出必来自不同输入”，只是函数的基本性质。例如平方函数 f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z 不是单射，因为 1≠−11\ne-11=−1 而 f(1)=f(−1)f(1)=f(-1)f(1)=f(−1)；但它仍满足第 2、3 式。

所有量词 ∀a∀b\forall a\forall b∀a∀b 都应理解为 a,ba,ba,b 从函数的定义域中取值，不能把定义域外的对象代入函数。

从 nnn 元集合到 nnn 元集合有多少函数

设有限集合 A,BA,BA,B 都有 nnn 个元素。本页先问不加单射限制时，从 AAA 到 BBB 有多少个函数。对 AAA 的每个元素，都可以独立地从 BBB 的 nnn 个元素中选一个作为输出；不同输入允许选到同一个输出。所以总数是

n⋅n⋯n⏟n 个因子=nn. \underbrace{n\cdot n\cdots n}_{n\text{ 个因子}}=n^n. n 个因子n⋅n⋯n​​=nn.

例如 n=2n=2n=2 时，若 A={a1,a2}A=\{a_1,a_2\}A={a1​,a2​}、B={b1,b2}B=\{b_1,b_2\}B={b1​,b2​}，两个输入各有两种输出选择，共有 22=42^2=422=4 个函数。

第二问要求函数单射，不同输入不可重复使用同一个输出。固定 AAA 的一种列举顺序后，第一个输入有 nnn 种选择，第二个只剩 n−1n-1n−1 种，依次减到最后一个输入只有 111 种。因此总数是

n(n−1)⋯2⋅1=n!. n(n-1)\cdots2\cdot1=n!. n(n−1)⋯2⋅1=n!.

这里的“第一个、第二个输入”只是为了计数而临时选的处理顺序，并不改变集合本身无序的性质。每个完整的输出分配只会按这个固定顺序被数到一次。由于 ∣A∣=∣B∣=n|A|=|B|=n∣A∣=∣B∣=n，单射用完 nnn 个不同输出时也必然覆盖 BBB；这一点将与后面的满射概念相连。

课件的逐项乘法叙述主要针对 n≥1n\ge1n≥1。若 n=0n=0n=0，从空集到空集有一个空函数，单射数为 0!=10!=10!=1；把无约束函数数写成 000^000 时需采用组合计数中的 00=10^0=100=1 约定，或直接单独处理空集情形。

满射：陪域每个元素都被命中

函数 f:A→Bf:A\to Bf:A→B 是满射（surjective，或 onto），当且仅当每个 b∈Bb\in Bb∈B 都有至少一个 a∈Aa\in Aa∈A 满足 f(a)=bf(a)=bf(a)=b：

∀b∈B  ∃a∈A  (f(a)=b). \forall b\in B\;\exists a\in A\;(f(a)=b). ∀b∈B∃a∈A(f(a)=b).

换句话说，函数的值域等于陪域：f(A)=Bf(A)=Bf(A)=B。满射允许不同输入取得同一输出，但不允许陪域里留下未被任何输入映到的元素。原页箭头图中，右侧的 x,y,zx,y,zx,y,z 都有箭头指入，而左侧有更多输入；它直观展示“覆盖全部右侧元素”，即使某些输出接收不止一个输入也不妨碍满射。

例一：f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(x)=x+1f(x)=x+1f(x)=x+1。对任意目标整数 bbb，选输入 a=b−1a=b-1a=b−1；它仍是整数，而且 f(a)=(b−1)+1=bf(a)=(b-1)+1=bf(a)=(b−1)+1=b。因此每个整数都被命中，fff 是满射。

例二：f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(x)=x2f(x)=x^2f(x)=x2。它不是满射。比如陪域中的整数 −1-1−1 没有任何整数原像，因为整数平方不可能为负。只要找到一个陪域元素没有原像，就足以否定满射。

满射判断与陪域的选择密切相关。同一平方规则若改以非负完全平方整数集为陪域，就会是满射；本页明确以全体整数 Z\mathbb ZZ 为陪域，所以答案是否定的。单射检查“不同输入是否撞值”，满射检查“每个目标是否被覆盖”，两个条件不可混淆。

双射：既单射又满射

函数 f:A→Bf:A\to Bf:A→B 是双射（bijection，也称 one-to-one correspondence），当且仅当它同时为单射和满射。单射保证不同的输入不会得到同一输出；满射保证 BBB 中每个元素都至少被某个输入命中。合起来就是：BBB 中每个元素恰好对应 AAA 中一个元素。

课件右侧的箭头图展示四个输入 a,b,c,da,b,c,da,b,c,d 与四个输出 x,y,z,wx,y,z,wx,y,z,w 的一一对应。每个左侧元素恰有一条输出箭头，右侧每个元素恰有一条箭头指入；所以不存在撞值，也没有遗漏目标。箭头交叉并不影响双射性质，重要的是每个端点的对应数量。

例如 f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(n)=n+1f(n)=n+1f(n)=n+1 是双射：若 f(a)=f(b)f(a)=f(b)f(a)=f(b)，减去 111 得 a=ba=ba=b，所以单射；对任意 m∈Zm\in\mathbb Zm∈Z，取 n=m−1n=m-1n=m−1 就有 f(n)=mf(n)=mf(n)=m，所以满射。相反，f(n)=n2f(n)=n^2f(n)=n2 从 Z\mathbb ZZ 到 Z\mathbb ZZ 既不是单射，也不是满射。

课件的三个英文说法可对应记忆：one-to-one = injection（单射）；onto = surjection（满射）；one-to-one and onto = bijection（双射）。其中“one-to-one correspondence”是双射的整体名称，不要把它误写成只满足单射就足够。

逆函数：把双射的箭头反过来

若 f:A→Bf:A\to Bf:A→B 是双射，则每个 b∈Bb\in Bb∈B 都恰好对应一个 a∈Aa\in Aa∈A，满足 f(a)=bf(a)=bf(a)=b。于是可以定义逆函数 f−1:B→Af^{-1}:B\to Af−1:B→A，令

f−1(b)=a⟺f(a)=b. f^{-1}(b)=a\quad\Longleftrightarrow\quad f(a)=b. f−1(b)=a⟺f(a)=b.

课件下方的图画出从左侧 AAA 中的 aaa 指向右侧 BBB 中的 bbb 的 fff 箭头，以及从 bbb 指回 aaa 的 f−1f^{-1}f−1 箭头。这正是逆函数的直观意义：给定原函数的输出，找回唯一的原输入。

为什么要求双射？满射保证 BBB 中每个 bbb 都有至少一个原像，逆向时不会出现“没有值”；单射保证每个 bbb 至多有一个原像，逆向时不会出现“一个输入对应多个输出”。两个条件合起来，反向对应才是从整个 BBB 到 AAA 的函数。课件称这种双射为可逆（invertible）。

例如 f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(n)=n+1f(n)=n+1f(n)=n+1，则 f−1(m)=m−1f^{-1}(m)=m-1f−1(m)=m−1。检验可得 f−1(f(n))=nf^{-1}(f(n))=nf−1(f(n))=n，以及 f(f−1(m))=mf(f^{-1}(m))=mf(f−1(m))=m。符号 f−1f^{-1}f−1 表示逆函数，一般不是 1/f1/f1/f；只有在另作数值倒数运算时才涉及分数 1/f(x)1/f(x)1/f(x)，两者不能混淆。

三个可逆性例子：规则相同也要看定义域

例一：f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(x)=x+1f(x)=x+1f(x)=x+1。它可逆。给定输出 yyy，唯一输入是 x=y−1x=y-1x=y−1，而 y−1y-1y−1 仍是整数。因此 f−1(y)=y−1f^{-1}(y)=y-1f−1(y)=y−1。可直接检验 f(f−1(y))=(y−1)+1=yf(f^{-1}(y))=(y-1)+1=yf(f−1(y))=(y−1)+1=y，以及 f−1(f(x))=(x+1)−1=xf^{-1}(f(x))=(x+1)-1=xf−1(f(x))=(x+1)−1=x。

例二：f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z，f(x)=x2f(x)=x^2f(x)=x2。它不可逆。不同整数可以有相同平方，课件举 f(4)=f(−4)=16f(4)=f(-4)=16f(4)=f(−4)=16，所以原函数不是单射；另外，负整数也没有平方原像，因此它也不是满射到 Z\mathbb ZZ。若试图把输出 161616 反向指定输入，就会同时遇到 444 与 −4-4−4，无法得到唯一值。

例三：f:R+→R+f:\mathbb R^+\to\mathbb R^+f:R+→R+，f(x)=x2f(x)=x^2f(x)=x2。课件的 R+\mathbb R^+R+ 是正实数，不包含 000。在这个定义域上，平方函数严格递增，不会把两个不同正数映成同一个数；对任意正输出 yyy，正数 y\sqrt yy​ 都是其原像。因此它既单射又满射，可逆且

f−1(y)=y(y>0). f^{-1}(y)=\sqrt y\qquad(y>0). f−1(y)=y​(y>0).

函数复合：先做 ggg，再做 fff

若 g:A→Bg:A\to Bg:A→B，f:B→Cf:B\to Cf:B→C，就可以把两步连接起来得到从 AAA 到 CCC 的复合函数（composition）f∘gf\circ gf∘g。其定义是

函数性质回顾：单射、满射、双射

本页是函数性质的总结，把三种判断放在一起比较。对函数 f:A→Bf:A\to Bf:A→B：

  • 单射（injection / one-to-one）：f(a)=f(b)⇒a=bf(a)=f(b)\Rightarrow a=bf(a)=f(b)⇒a=b，即不同输入不会得到同一输出。它检查有没有“撞值”。右上示意图里 a,b,ca,b,ca,b,c 分别指向 1,2,31,2,31,2,3，而 BBB 中的 444 没被指到；仍是单射。
  • 满射（surjection / onto）：对每个 y∈By\in By∈B，至少有一个 x∈Ax\in Ax∈A 使 f(x)=yf(x)=yf(x)=y，即值域等于陪域。中间示意图有四个输入、三个目标，所有目标都被指到；其中某个目标由多个输入命中也允许。
  • 双射（bijection / one-to-one correspondence）：既单射又满射。下方示意图的三个输入与三个目标一一配对，每个目标恰好由一个输入命中。

可以用两个问题快速检查：有没有两个不同输入撞在同一输出上？若有，则非单射。陪域里有没有元素完全没有原像？若有，则非满射。两种问题都回答“没有”，函数才是双射。

这些性质针对的是完整的函数声明 f:A→Bf:A\to Bf:A→B。改变定义域或陪域，判定结果可能改变：例如整数平方在全体整数上不单射，把定义域限制为正实数后则可单射；把陪域取为正实数时，正实数平方还可满射。本页三个小图也说明：单射可有未用目标，满射可有多个输入共用目标，双射两者都不出现。
