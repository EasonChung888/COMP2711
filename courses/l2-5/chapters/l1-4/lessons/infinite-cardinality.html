无限集合的基数与可数性

有限集合可以数出元素个数；无限集合则用一一对应比较大小。若无限集合 A,BA,BA,B 之间存在双射 f:A→Bf:A\to Bf:A→B，就说它们有相同基数。这里“双射”要求每个 AAA 元素对应唯一的 BBB 元素，而且 BBB 的元素全部被覆盖。

本课的自然数集是 N={0,1,2,…}\mathbb N=\{0,1,2,\ldots\}N={0,1,2,…}，其基数记作 ℵ0\aleph_0ℵ0​，读作 aleph-nought（阿列夫零）。一个无限集合 SSS 若满足 ∣S∣=ℵ0|S|=\aleph_0∣S∣=ℵ0​，课件称其为可数（countable）；更明确地说是可数无限。这等价于能把 SSS 的元素排成由自然数编号的序列 s0,s1,s2,…s_0,s_1,s_2,\ldotss0​,s1​,s2​,…，使每个元素恰好出现一次。另有些教材把有限集合也纳入“可数”的广义用法；本页语境明确针对无限集合。

无限集合会出现有限集合没有的现象：真子集也可能与原集合等势。非负偶数集 E={0,2,4,…}E=\{0,2,4,\ldots\}E={0,2,4,…} 是 N\mathbb NN 的真子集，但 n↦2nn\mapsto2nn↦2n 给出 N\mathbb NN 到 EEE 的双射，所以 ∣E∣=ℵ0|E|=\aleph_0∣E∣=ℵ0​。另一方面，N\mathbb NN 是整数集 Z\mathbb ZZ 的真子集，课件也用它提示 Z\mathbb ZZ 仍可与 N\mathbb NN 一一对应。

若无限集合不能与 N\mathbb NN 一一对应，就称为不可数（uncountable）。本页最后提出问题：N\mathbb NN 与 000 到 111 之间的实数哪个基数更大？这是在引出不同层次的无限，而不能仅凭两个集合都“有无限多个元素”就说它们一样大；需要构造双射或证明双射不可能存在。

希尔伯特旅馆：满房仍能接纳新客

希尔伯特旅馆是理解可数无限的一种思想实验。旅馆房间编号为 0,1,2,…0,1,2,\ldots0,1,2,…，每间都已有一位客人；原客人 xxx 住在 xxx 号房。虽然没有“空房”，仍可以用一一且不冲突的重新分配腾出位置。

新来一位客人。让每位原客人 xxx 搬到 x+1x+1x+1 号房。不同 xxx 对应不同的新房号，原客人都仍有房间，且 000 号房空出来，给新客人入住。

新来 100100100 位客人。让原客人 xxx 搬到 x+100x+100x+100 号房。这样 0,1,…,990,1,\ldots,990,1,…,99 共 100100100 间房空出，恰好可安排新客。若新来的是任意有限的 kkk 位，也可以统一改为 x↦x+kx\mapsto x+kx↦x+k。

新来可数无限多位客人。让原客人 xxx 搬到偶数号房 2x2x2x。这保留了所有原客人并占满偶数号房，全部奇数号房 1,3,5,…1,3,5,\ldots1,3,5,… 则空出。把新客人依序编号为 0,1,2,…0,1,2,\ldots0,1,2,…，安排第 jjj 位入住 2j+12j+12j+1 号房，便也能让每人恰有一房。

这个故事展示的是可数集合与它的真子集可以等势，以及两个可数无限群体仍能排成一个可数序列。它是关于无限集合的对应关系的模型；现实中无法在有限时间内让无限多人同时完成搬迁。课件底部给出一段配套视频链接，理解上述映射并不依赖联网观看。

可数多辆巴士、每辆可数多位客人

上一页只加进一辆可数无限的巴士；本页把情形扩大为可数无限多辆巴士，且每辆又有可数无限多位客人。再加上原旅馆里已经入住的可数无限多人，问题是能否把所有人依次安排进 0,1,2,…0,1,2,\ldots0,1,2,… 号房。

课件用表格组织人：第一行是原住客 HR0,HR1,…\mathrm{HR}0,\mathrm{HR}1,\ldotsHR0,HR1,…；之后第 iii 行是第 iii 辆巴士的乘客 BiS1,BiS2,…\mathrm{B}i\mathrm{S}1,\mathrm{B}i\mathrm{S}2,\ldotsBiS1,BiS2,…。每个人对应表格中的一个格子。如果按“先列完第一行，再列第二行”的办法，第一行已经无限长，永远到不了后面的巴士，所以需要另一种顺序。

图中的红线采用斜对角穿行：先列 HR0\mathrm{HR}0HR0，然后 HR1,B1S1\mathrm{HR}1,\mathrm{B}1\mathrm{S}1HR1,B1S1，再列 B2S1,B1S2,HR2\mathrm{B}2\mathrm{S}1,\mathrm{B}1\mathrm{S}2,\mathrm{HR}2B2S1,B1S2,HR2，随后进入下一条对角线，得到 HR3,…\mathrm{HR}3,\ldotsHR3,…。这样每条对角线只有有限个格子，而且每个固定的“第几辆巴士、第几个座位”都位于某一条有限编号的对角线上，最终一定会被列到。

一旦把所有原住客和新客排成序列 c0,c1,c2,…c_0,c_1,c_2,\ldotsc0​,c1​,c2​,…，就把 cjc_jcj​ 分配到 jjj 号房。这个过程展示可数个可数集合的并仍可数，也解释了为何“无限乘无限”在这里仍能与自然数编号一一对应。关键不是一句“房间无限，所以够住”，而是给出不会遗漏任何客人、也不会重复占房的枚举方法。

对角线法：为什么不可数多位客人住不进可数房间

本页从前两页的可数客群转向不可数客群。设每位新客人的 ID 是一个无限长的 0/10/10/1 序列。若要说明所有这类无限位串不能被房间 0,1,2,…0,1,2,\ldots0,1,2,… 一一容纳，可以先假设已经把它们全部列成一个序列：第 111 行是第 111 位的 ID，第 222 行是第 222 位的 ID，依此类推。这里“按 ID 递增”不是论证所需条件；关键只是声称存在一份完整的可数列表。

现在构造一个新 ID d=d1d2d3…d=d_1d_2d_3\ldotsd=d1​d2​d3​…：令 did_idi​ 与列表中第 iii 行的第 iii 位相反。若对角线前三位是 0,1,10,1,10,1,1，新 ID 的前三位就是 1,0,01,0,01,0,0，课件写作 100…100\ldots100…。新 ID 与第 111 行至少在第 111 位不同，与第 222 行至少在第 222 位不同；一般地，它与第 iii 行至少在第 iii 位不同，所以不等于列表上的任何一个 ID。

但 ddd 仍是一个无限长 0/10/10/1 序列，本应在“全部 ID”的列表中，形成矛盾。因此不可能把所有无限二进制序列列成自然数编号的清单；这就是康托尔对角线论证。若每个这类序列对应一位新客，房间只有可数多间，那么无论怎样重新安排，都会有客人没有房间。

这里与上一页的“斜对角枚举”结论相反，是因为对象的结构不同：上一页每位客人由两个有限整数编号确定，可以沿有限对角线逐个列出；本页每个 ID 是无限多个二进制位，对任何可数列表都能按对角线制造出一个遗漏项。原页表格只画了前几行和若干位，用于展示构造方式；严格论证需要 ID 为无限序列，并且讨论的是所有这样的序列。

L1.4 第 37 页：对角线论证的 ID 范围

课件称客人 ID 为“0、1 字符串”，并说“按 ID 递增”安排，再翻转每行的对角位。严格的对角线论证需要讨论所有无限长二进制序列；若 ID 只允许有限长字符串，它们本身是可数的，不能由这段构造推出不可数。若只取无限位串的某个特定子集，翻转得到的新串也未必属于该子集。

“按 ID 递增”不是所需假设，也不应作为无限位串可数枚举的理由。正确反证起点是：假设所有无限二进制序列存在某个自然数编号的完整列表；逐行翻转对角位可构造出仍属于该集合、却不在列表中的新序列，因而否定完整列表的存在。原课件图和逐页讲解原文保持不变。

三个可数集合的一一对应

要证明一个无限集合 SSS 可数，可以给出从本课自然数集 N={0,1,2,…}\mathbb N=\{0,1,2,\ldots\}N={0,1,2,…} 到 SSS 的双射。本页给出三个例子。

正整数 Z+={1,2,3,…}\mathbb Z^+=\{1,2,3,\ldots\}Z+={1,2,3,…}。定义 f(n)=n+1f(n)=n+1f(n)=n+1。自然数 0,1,2,…0,1,2,\ldots0,1,2,… 依次对应正整数 1,2,3,…1,2,3,\ldots1,2,3,…。不同自然数给出不同正整数，而且每个正整数 kkk 都来自 n=k−1n=k-1n=k−1，故是双射。

非负偶整数 E={0,2,4,6,…}E=\{0,2,4,6,\ldots\}E={0,2,4,6,…}。定义 f(n)=2nf(n)=2nf(n)=2n。它把 0,1,2,3,…0,1,2,3,\ldots0,1,2,3,… 对应到 0,2,4,6,…0,2,4,6,\ldots0,2,4,6,…；每个非负偶数 2k2k2k 都由 kkk 取得，且没有撞值。因此 EEE 虽是 N\mathbb NN 的真子集，仍与 N\mathbb NN 等势。原页右侧图把目标行标成 “even Z+\mathbb Z^+Z+”，却又列入 000；准确名称应是非负偶整数，因为 0∉Z+0\notin\mathbb Z^+0∈/Z+。

全部整数 Z\mathbb ZZ。按 0,1,−1,2,−2,3,−3,…0,1,-1,2,-2,3,-3,\ldots0,1,−1,2,−2,3,−3,… 排列。课件给出从 N\mathbb NN 到 Z\mathbb ZZ 的分段函数：

f(n)={−n/2,n 为偶数,(n+1)/2,n 为奇数. f(n)= \begin{cases} -n/2,&n\text{ 为偶数},\\ (n+1)/2,&n\text{ 为奇数}. \end{cases} f(n)={−n/2,(n+1)/2,​n 为偶数,n 为奇数.​

偶数索引 0,2,4,…0,2,4,\ldots0,2,4,… 给出 0,−1,−2,…0,-1,-2,\ldots0,−1,−2,…；奇数索引 1,3,5,…1,3,5,\ldots1,3,5,… 给出 1,2,3,…1,2,3,\ldots1,2,3,…。两个分支的输出不会重复，且覆盖所有整数，所以这是双射，∣Z∣=ℵ0|\mathbb Z|=\aleph_0∣Z∣=ℵ0​。

这三个构造都在证明存在一一对应，而不是声称 N\mathbb NN、Z+\mathbb Z^+Z+、EEE、Z\mathbb ZZ 是相同的集合。它们成员不同，基数却相同。

用对角线枚举正有理数

每个正有理数都能写成 p/qp/qp/q，其中 p,q∈Z+p,q\in\mathbb Z^+p,q∈Z+。课件把这些分数排进二维表：第 qqq 行固定分母 qqq，列从左到右依次取分子 p=1,2,3,…p=1,2,3,\ldotsp=1,2,3,…。例如第一行是 1/1,2/1,3/1,…1/1,2/1,3/1,\ldots1/1,2/1,3/1,…，第二行是 1/2,2/2,3/2,…1/2,2/2,3/2,\ldots1/2,2/2,3/2,…。

若一行一行数，第一行无限长，永远到不了第二行。课件改沿图中的红色斜对角线走，也就是按 p+qp+qp+q 从小到大处理：1/11/11/1，再 2/1,1/22/1,1/22/1,1/2，再 1/3,2/2,3/11/3,2/2,3/11/3,2/2,3/1，如此继续。每个固定的正整数对 (p,q)(p,q)(p,q) 都有有限的和 p+qp+qp+q，最终会落在某条被访问的对角线上。

要注意不同分数形式可能表示同一个有理数，例如 1/1=2/2=3/31/1=2/2=3/31/1=2/2=3/3。若要得到真正的“一一对应”，遍历时跳过已经出现的数值；等价地，只保留 p,qp,qp,q 互质的最简分数。这样每个正有理数最终出现一次，说明正有理数集是可数无限的。

课件最后问所有有理数是否可数，答案也是肯定的。全体有理数可以分成正有理数、负有理数和 {0}\{0\}{0}。负有理数可由正有理数逐个取相反数而枚举；再把这两列与单独的 000 交错安排，就能列出所有有理数。课件用“两个可数集合的并仍可数”概括这一步；这里的并实际还要加入一个有限的单元素集合。

斜对角枚举与上一页的无限二进制位串对角线法用途不同：前者列举有限整数对，后者针对任何列表构造一个无限序列的遗漏项。不能因为都画了对角线就认为结论相同。

000 与 111 之间的实数不可数

本页用康托尔对角线法证明：区间 (0,1)(0,1)(0,1) 中的实数不能按自然数编号全部列出。反设它是可数的，存在一张完整列表

r1=0.d11d12d13…,r2=0.d21d22d23…,r3=0.d31d32d33…,…, r_1=0.d_{11}d_{12}d_{13}\ldots,\quad r_2=0.d_{21}d_{22}d_{23}\ldots,\quad r_3=0.d_{31}d_{32}d_{33}\ldots,\quad\ldots, r1​=0.d11​d12​d13​…,r2​=0.d21​d22​d23​…,r3​=0.d31​d32​d33​…,…,

构造一个新实数 r=0.c1c2c3…r=0.c_1c_2c_3\ldotsr=0.c1​c2​c3​…，让 cic_ici​ 不同于对角线上的 diid_{ii}dii​。为避开十进制小数表示不唯一的问题，可以明确规定：若 dii=1d_{ii}=1dii​=1，令 ci=2c_i=2ci​=2；否则令 ci=1c_i=1ci​=1。这样 cic_ici​ 总是 111 或 222，与 diid_{ii}dii​ 不同，且新小数不会出现无限尾随的 999 或成为 000、111。

对列表中的任意第 iii 行，rrr 与 rir_iri​ 至少在第 iii 位小数不同，因此 r≠rir\ne r_ir=ri​。但 rrr 本身也在 (0,1)(0,1)(0,1) 内，按“列表完整”的假设本应出现在某一行；这与“它不等于任何一行”矛盾。故不存在这样的完整可数列表，(0,1)(0,1)(0,1) 不可数，基数严格大于 N\mathbb NN。

可数集合回顾与连续统假设

本页重申：要证明无限集合 SSS 可数，可以构造从 N\mathbb NN 到 SSS 的双射，也就是把 SSS 的元素排成自然数编号、不遗漏也不重复的序列。例子取非负偶数集 E={0,2,4,…}E=\{0,2,4,\ldots\}E={0,2,4,…}，定义

f:N→E,f(a)=2a. f:\mathbb N\to E,\qquad f(a)=2a. f:N→E,f(a)=2a.

单射性：若 f(a)=f(b)f(a)=f(b)f(a)=f(b)，即 2a=2b2a=2b2a=2b，两边除以非零的 222，得 a=ba=ba=b。满射性：任取 a′∈Ea'\in Ea′∈E，按非负偶数的定义存在 k∈Nk\in\mathbb Nk∈N 使 a′=2k=f(k)a'=2k=f(k)a′=2k=f(k)。所以 fff 是双射，∣E∣=∣N∣=ℵ0|E|=|\mathbb N|=\aleph_0∣E∣=∣N∣=ℵ0​。

课件还回顾：整数集 Z\mathbb ZZ 和有理数集 Q\mathbb QQ 可数；实数集 R\mathbb RR 不可数。整数可用 0,1,−1,2,−2,…0,1,-1,2,-2,\ldots0,1,−1,2,−2,… 排列；有理数可先按正整数分子、分母的对角线列举，再处理负数和零。实数在 (0,1)(0,1)(0,1) 内已不可数，因此更大的 R\mathbb RR 也不可能是可数的。

最后提到连续统假设（continuum hypothesis）：是否不存在基数严格介于 ∣N∣|\mathbb N|∣N∣ 与 ∣R∣|\mathbb R|∣R∣ 之间的集合？“自然数比实数少”已由对角线法证明，但这没有自动回答是否存在中间大小。课件把连续统假设列为希尔伯特第一问题。作为进一步背景，在通常的 ZFC 集合论公理下，这个假设是独立的：若 ZFC 一致，单靠这些公理既不能证明它，也不能证明其否定。这与“命题已经被证明为真或假”不同。相关原始论文见 Gödel 的相容性结果 与 Cohen 的独立性结果；本页课程目标主要是识别该假设所比较的两个基数。

用单射比较无限基数：施罗德—伯恩斯坦定理

课件写“若存在单射 f:A→Bf:A\to Bf:A→B，但 fff 不是双射，则 ∣A∣<∣B∣|A|<|B|∣A∣<∣B∣”。这对无限集合是错误的：取 A=B=NA=B=\mathbb NA=B=N，f(n)=2nf(n)=2nf(n)=2n 是单射，但未命中任何奇数，故不是双射；然而 ∣A∣=∣B∣|A|=|B|∣A∣=∣B∣，例如恒等函数就是两边的双射。

幂集总更大，以及不可计算函数

本讲最后一页给出两个关于无限的进一步结果。首先是康托尔幂集定理：对任何集合 SSS，不论有限或无限，都有

∣S∣<∣P(S)∣. |S|<|\mathcal P(S)|. ∣S∣<∣P(S)∣.

有限情形可由 ∣S∣=n|S|=n∣S∣=n、∣P(S)∣=2n>n|\mathcal P(S)|=2^n>n∣P(S)∣=2n>n 看出。无限情形不能只靠普通数字直觉；关键是：假设存在一个把 SSS 中元素逐个对应到所有子集的满射 h:S→P(S)h:S\to\mathcal P(S)h:S→P(S)，构造 D={s∈S∣s∉h(s)}D=\{s\in S\mid s\notin h(s)\}D={s∈S∣s∈/h(s)}。若 D=h(d)D=h(d)D=h(d) 对某个 d∈Sd\in Sd∈S 成立，就会得到 d∈D  ⟺  d∉Dd\in D\iff d\notin Dd∈D⟺d∈/D，矛盾。因此没有这样的满射，幂集基数严格更大。例如 ∣R∣<∣P(R)∣|\mathbb R|<|\mathcal P(\mathbb R)|∣R∣<∣P(R)∣。

课件接着定义：函数可计算，是指存在程序能对其定义域中的任意输入在有限步骤内算出正确函数值；否则称不可计算。从 N\mathbb NN 到 {0,1}\{0,1\}{0,1} 的每个函数都对应一个无限位串 f(0)f(1)f(2)…f(0)f(1)f(2)\ldotsf(0)f(1)f(2)…，所以这类函数有不可数多。但程序本身可编码成有限位串，而所有有限位串只有可数多。一个程序至多给出一个确定函数，故程序不可能覆盖所有 N→{0,1}\mathbb N\to\{0,1\}N→{0,1} 的函数；必有不可计算的函数。原页第二个示例 f2f_2f2​ 的自变量与函数名有重复笔误；它想展示另一串 0101…0101\ldots0101…，不影响计数论证。

最后是停机问题（halting problem）：不存在一个通用程序，能对任意给定的程序及输入总在有限时间内正确判定该程序在该输入上会不会停机。课件写“是否在某个输入上终止”，措辞容易与标准的“给定输入上的停机判断”混淆；本页应先按后者理解停机问题的核心结论。停机不可判定是一个比上面的简单基数计数更具体的不可计算性结果，可参见 Turing 原论文。

原题 PDF · 第 6 页

Decide if the following sets are countable or uncountable. Let N\mathbb NN be the set of natural numbers. P(S)P(S)P(S) denotes the power set of SSS. No need to justify your answers.

  1. N2\mathbb N^2N2
查看答案与解析

Provenance: published official answer, independently checked and expanded below.

中文解答

答案。 N2\mathbb N^2N2 是 countably infinite，故选择 countable。

推导。

  1. 按两坐标和 s=a+bs=a+bs=a+b 从小到大排列自然数有序对 (a,b)(a,b)(a,b)。对每个固定的 sss，满足条件的对只有有限多个，可以按第一坐标从小到大全部列出，再进入下一条 diagonal。
  2. 每个有序对的坐标和都是某个有限自然数，所以这份按对角线扫描的序列最终必定列到它，没有遗漏；由此集合至多可数。固定一个合法第二坐标，让第一坐标依次取所有自然数，又得到无限多个不同有序对，所以集合无限可数。自然数是否包括零只改变最先几条对角线，不改变论证。

English solution

Answer. Countable.

Derivation/proof. For each possible sum sss, list all pairs (a,b)∈N2(a,b)\in\mathbb N^2(a,b)∈N2 with a+b=sa+b=sa+b=s. Each diagonal is finite; scanning the diagonals in increasing sss reaches every pair because each pair has a finite sum. This constructs an enumeration. There are infinitely many distinct pairs with one coordinate fixed, so the set is countably infinite. The argument works with either convention for whether 0 belongs to N\mathbb NN.

容易出错的地方

  • 认为二维自然数格点比一维自然数多就不可数，忽略了 diagonal enumeration。 / Diagonal enumeration reaches all pairs.
  • 在每个固定第一坐标下先列完无限多第二坐标，会永远到不了下一行。 / Use finite diagonals rather than infinite rows.

  1. 假设所有自然数子集能列为 A1,A2,…A_1,A_2,\ldotsA1​,A2​,…；如自然数包括零，可先重新编号。定义 diagonal 集合 D={n:n∉An}D=\{n:n\notin A_n\}D={n:n∈/An​}。这个规则为每个自然数确定是否取入，所以 DDD 本身是合法的自然数子集。

Answer. Uncountable.

Derivation/proof. Suppose all subsets were listed as A1,A2,…A_1,A_2,\ldotsA1​,A2​,… (reindex naturals starting at 1 if necessary). Define D={n:n∉An}D=\{n:n\notin A_n\}D={n:n∈/An​}.
