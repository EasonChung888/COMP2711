# 集合恒等式：单位、支配、幂等、补集与交换

这一页的正文是一张**图片表格**，文字提取层只得到标题；以下按原页图逐项解释。设 $U$ 为固定全集，$A,B\subseteq U$，$\varnothing$ 是空集。

| 名称 | 原页恒等式 | 为什么成立 |
|---|---|---|
| **单位律**（identity laws） | $A\cup\varnothing=A$；$A\cap U=A$ | 与“没有元素”做并集不增加成员；与“所有允许元素”做交集不删除成员。 |
| **支配律**（domination laws） | $A\cup U=U$；$A\cap\varnothing=\varnothing$ | 并上全集后得到所有允许元素；与空集求交找不到任何共同元素。 |
| **幂等律**（idempotent laws） | $A\cup A=A$；$A\cap A=A$ | 同一个集合出现两次，不改变成员条件。 |
| **双重补集律**（complementation law） | $\overline{\overline A}=A$ | 在同一全集 $U$ 内，“不属于 $A$ 的补集”就是属于 $A$。 |
| **交换律**（commutative laws） | $A\cup B=B\cup A$；$A\cap B=B\cap A$ | 成员条件中的“或”与“且”交换前后两项不改变真假。 |

这些都是**集合相等式**，可用上一页学过的成员判断来核对。例如对任意 $x\in U$，$x\in A\cup\varnothing$ 当且仅当 $x\in A$ 或 $x\in\varnothing$；后一项恒假，所以条件化为 $x\in A$。其余各式也能按类似方式检验。

尤其注意补集的横线必须相对于**同一个全集**。若中途改变 $U$，$\overline{\overline A}=A$ 的两次补集就不再是在同一语境下计算。表中 $U$ 与 $\varnothing$ 扮演相反的边界角色，记忆时可以结合“成员是否可能出现”理解，而非只背公式。
