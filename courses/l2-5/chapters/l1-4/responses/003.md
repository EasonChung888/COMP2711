# 常用数集的记号

本页列出后续例题会频繁使用的数集。**务必以这份课件的约定为准**：这里的自然数集 $\mathbb N$ **包含 $0$**。

| 记号 | 本页含义 | 例子或范围 |
|---|---|---|
| $\mathbb N$ | 自然数 | $\{0,1,2,3,\ldots\}$ |
| $\mathbb Z$ | 整数 | $\{\ldots,-3,-2,-1,0,1,2,3,\ldots\}$ |
| $\mathbb Z^+$ | 正整数 | $\{1,2,3,\ldots\}$ |
| $\mathbb Z^-$ | 负整数 | $\{-1,-2,-3,\ldots\}$ |
| $\mathbb R$ | 实数 | 数轴上的实数 |
| $\mathbb R^+$ | 正实数 | 大于 $0$ 的实数 |
| $\mathbb R^-$ | 负实数 | 小于 $0$ 的实数 |
| $\mathbb Q$ | 有理数 | 可写成 $a/b$，其中 $a,b\in\mathbb Z$ 且 $b\ne0$ |

上标的 $+$、$-$ 在这里表示**正数部分**和**负数部分**，不是“把集合加上或减去什么”。因此 $0\in\mathbb N$、$0\in\mathbb Z$、$0\in\mathbb R$、$0\in\mathbb Q$，但 $0\notin\mathbb Z^+$、$0\notin\mathbb Z^-$，也不属于 $\mathbb R^+$ 或 $\mathbb R^-$。

自然数是否包含 $0$ 在不同教材中有不同约定；本讲已明确写出 $\mathbb N=\{0,1,2,\ldots\}$，做题时应保持一致。常见包含关系是 $\mathbb N\subseteq\mathbb Z\subseteq\mathbb Q\subseteq\mathbb R$；例如每个整数都能写成分母为 $1$ 的分数，所以属于 $\mathbb Q$。
