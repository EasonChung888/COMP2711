# 对角线法：为什么不可数多位客人住不进可数房间

本页从前两页的**可数**客群转向**不可数**客群。设每位新客人的 ID 是一个**无限长**的 $0/1$ 序列。若要说明所有这类无限位串不能被房间 $0,1,2,\ldots$ 一一容纳，可以先**假设**已经把它们全部列成一个序列：第 $1$ 行是第 $1$ 位的 ID，第 $2$ 行是第 $2$ 位的 ID，依此类推。这里“按 ID 递增”不是论证所需条件；关键只是**声称存在一份完整的可数列表**。

现在构造一个新 ID $d=d_1d_2d_3\ldots$：令 $d_i$ 与列表中**第 $i$ 行的第 $i$ 位**相反。若对角线前三位是 $0,1,1$，新 ID 的前三位就是 $1,0,0$，课件写作 $100\ldots$。新 ID 与第 $1$ 行至少在第 $1$ 位不同，与第 $2$ 行至少在第 $2$ 位不同；一般地，它与第 $i$ 行至少在第 $i$ 位不同，所以**不等于列表上的任何一个 ID**。

但 $d$ 仍是一个无限长 $0/1$ 序列，本应在“全部 ID”的列表中，形成矛盾。因此不可能把所有无限二进制序列列成自然数编号的清单；这就是**康托尔对角线论证**。若每个这类序列对应一位新客，房间只有可数多间，那么无论怎样重新安排，都会有客人没有房间。

这里与上一页的“斜对角枚举”结论相反，是因为对象的结构不同：上一页每位客人由**两个有限整数编号**确定，可以沿有限对角线逐个列出；本页每个 ID 是**无限多个二进制位**，对任何可数列表都能按对角线制造出一个遗漏项。原页表格只画了前几行和若干位，用于展示构造方式；严格论证需要 ID 为无限序列，并且讨论的是**所有**这样的序列。
