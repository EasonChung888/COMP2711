   Properties of Functions and
   Cardinality of Infinite Sets

For two sets A and B
• If there is bijection 𝑓:A→B,      then |A| =   |B| (Bijection principle)
• If there is injection 𝑓:A→B, then |A| ≤       |B|
• If there is injection 𝑓:A→B, but not bijection, then |A|<          |B|

Schröder-Bernstein Theorem: if |A| ≤         |B| and |B| ≤  |A|, then |A|=  |B|.
