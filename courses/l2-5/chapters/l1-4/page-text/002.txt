   Set
▪ Definition: A set is an unordered collection of objects
  The objects in a set are called the elements or
  members of the set. A set is said to contain its
  elements. We write a 𝑎        ∈ 𝐴 to denote that 𝑎 is an
  element of the set 𝐴 and 𝑎        ∉  𝐴 to denote that 𝑎 is not an
  elements of 𝐴.
▪ Roster method for describing sets:
   ▪  List all elements of a set explicitly
   ▪  Use … when the pattern is obvious.
▪ Example
   ▪  The   set  of all odd   positive   integers    less  than  10  can
      be denoted by {1,     3,5, 7,9}.
   ▪  The   set of  all odd   positive   integers   less  than   100 can
      be denoted by {1,     3,5, … ,99}.
