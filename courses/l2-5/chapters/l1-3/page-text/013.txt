Example on Application of multiple rules of inference 2

▪ Given premises: ¬p ∧ q, r → p, ¬r → s, and s → t,
  conclude     t

   ▪  1 ¬p ∧ q                 Premise
   ▪  2. ¬p                    Simplification using (1)
   ▪  3. r → p                 Premise
   ▪  4. ¬r                    Modus tollens using (2) and (3)
   ▪  5. ¬r → s                Premise
   ▪  6. s                     Modus ponens using (4) and (5)
   ▪  7. s → t                 Premise
   ▪  8. t                     Modus ponens using (6) and (7)
