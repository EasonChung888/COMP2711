# 用最后一位检验奇偶事件

四位 bit string 均匀生成，令 $E$ 为首位是 1，$F$ 为 1 的总数是偶数。

固定前三位，假设其中有 $k$ 个 1。$k$ 为偶数时，末位选 0 才满足 $F$；$k$ 为奇数时，末位则要选 1。无论前三位是什么，末位两个等可能选择中恰好一个成功，故 $p(F)=1/2$。

给定首位为 1，后三位仍均匀随机。对每个允许的前三位组合，末位还是二选一，因此

$$p(F\mid E)=\frac12=p(F),$$

两事件独立。列举也可核对：交集为 $\{1111,1100,1010,1001\}$，在八个首位是 1 的串中占 $4/8$。

“末位决定奇偶”不能理解为只看末位便知道 $F$ 是否发生，还要知道前三位的奇偶。证明利用的是公平且独立的末位：它对任何先前状态都给出一半成功机会。若末位有偏，或各位相关，就不能直接沿用这个论证。
