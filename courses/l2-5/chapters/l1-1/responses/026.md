# 双条件：两边互相保证

**双条件命题（biconditional statement）**写作 $p\leftrightarrow q$，读作“$p$ 当且仅当 $q$”，英文常说 **$p$ if and only if $q$**，缩写为 **$p$ iff $q$**。它把两个方向一起要求：$p\to q$ **且** $q\to p$。

| $p$ | $q$ | $p\leftrightarrow q$ |
|---|---|---|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | T |

因此，$p$ 与 $q$ **真值相同**时双条件为真，真值不同时为假。最后一行容易忽略：两边都假时，两个方向的条件命题都没有出现“真前提、假结论”的反例，所以 $p\leftrightarrow q$ 仍为真。

课件列出的几种说法意思相同：“$p$ 当且仅当 $q$”；“$p$ 是 $q$ 的**必要且充分条件**”；“如果 $p$ 那么 $q$，反过来也一样”。例如，对一个整数 $n$，“$n$ 是偶数，当且仅当 $n$ 除以 $2$ 余 $0$”要求两方向都成立：偶数必余 $0$，余 $0$ 也必为偶数。

检查双条件时，应分别证明或核对两个箭头。只证明 $p\to q$，不能擅自补上 $q\to p$。
