# 英文条件句的不同说法，箭头方向相同

这一页把多种英文表达都翻译成同一逻辑式 **$p\to q$**。读句子时先找出“发生什么就足以保证什么”，不要只凭 $p$、$q$ 在英语句中的先后位置判断箭头。

| 英文说法 | 可理解为 |
|---|---|
| if $p$, then $q$；$p$ implies $q$ | 如果 $p$，那么 $q$；$p$ 蕴含 $q$ |
| $p$ is a sufficient condition for $q$ | $p$ 是 $q$ 的充分条件 |
| $p$ only if $q$ | 只有 $q$ 时才可能有 $p$ |
| $q$ if $p$；$q$ when $p$ | 在 $p$ 成立时，$q$ 成立 |
| $q$ follows from $p$ | $q$ 可由 $p$ 推出 |
| $q$ is a necessary condition for $p$ | $q$ 是 $p$ 的必要条件 |

最容易看反的是 **“$p$ only if $q$”**。它说的是：没有 $q$，就不可能有 $p$；即 $\neg q\to\neg p$。这与 $p\to q$ 方向相同，**不是** $q\to p$。

课件的例子是“公司只有在资金充足时才可能成功”。令 $p$ 为“公司成功”，$q$ 为“资金充足”，便得到 $p\to q$：成功需要充足资金。它没有说“有了充足资金就一定成功”；资金充足是这里的必要条件，并未被宣称为充分条件。把每个英文版本都改写为“如果 $p$，那么 $q$”，可以统一检查方向。
