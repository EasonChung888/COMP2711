条件命题：什么时候“如果 ppp，那么 qqq”是假的？

条件命题（conditional statement）写作 p→qp\to qp→q，读作“如果 ppp，那么 qqq”，也叫蕴含（implication）。其中 ppp 是前提或假设（hypothesis / premise），qqq 是结论或后果（conclusion / consequence）。

课件的真值表是：

ppp qqq p→qp\to qp→q
T T T
T F F
F T T
F F T

唯一使 p→qp\to qp→q 为假的情况是：前提真的发生了，承诺的结论却没有发生。例如，“如果一个整数是 4 的倍数，那么它是偶数”不会被一个不是 4 的倍数的整数反驳；要反驳它，必须找到一个“是 4 的倍数但不是偶数”的整数。

当 ppp 为假时，p→qp\to qp→q 在这套形式定义下为真，称为空真（vacuously true）。这不是说 qqq 自动变真，而是说没有出现“前提成立、结论失败”的反例。最后，形式逻辑只按 ppp、qqq 的真值计算 p→qp\to qp→q；两句话在日常语义上不一定有因果关系。箭头方向也重要：p→qp\to qp→q 本身没有断言 q→pq\to pq→p。

用具体例子检查条件命题

判断“如果 ppp，那么 qqq”的真值，先分别看前提 ppp 和结论 qqq，再套用上一页的规则：只有 ppp 真、qqq 假时，p→qp\to qp→q 才是假。

  1. “如果北京是中国的首都，那么北京是中国的城市”：课件把前提和结论都视为真，因此整个条件命题为真。
  2. “如果北京是中国的城市，那么北京是中国的首都”：在北京这个具体对象上，前提和结论也都真，因此这个条件命题也为真。但不能由此概括成“任何中国城市都是首都”；单个真例子不能证明那个普遍命题。
  3. “如果月亮由绿色奶酪构成，那么我比 Bill Gates 更富有”：前提为假，所以按形式逻辑定义，整个条件命题为真，不需要先验证结论。
  4. “如果月亮不是由绿色奶酪构成，那么我比 Bill Gates 更富有”：课件的设定把前提视为真、把说话者比 Bill Gates 更富有视为假，于是出现唯一的反例组合 T→F，整个条件命题为假。

这里的财富比较只是课件为了展示真值表所作的情境设定，不是关于当前个人财富的事实判断。第三、四句最能说明“假前提时为真”与“真前提、假结论时为假”的区别；第一、二句则提醒我们，要把某个具体条件句为真与一般规律成立分开。

充分条件与必要条件：同一个箭头的两种读法

当 p→qp\to qp→q 被当作一条保证关系时，只要 ppp 成立，qqq 就必须成立。因此可以说：ppp 是 qqq 的充分条件（sufficient condition），因为有了 ppp 足以保证 qqq；qqq 是 ppp 的必要条件（necessary condition），因为若 ppp 成立就不能缺少 qqq。

课件用一句竞选承诺作例子：“如果我当选，那么税收会降低。”令 ppp 为“我当选”，qqq 为“税收降低”。在假定这条承诺关系成立的前提下：

  • 当选 ppp 足以保证减税 qqq，所以 ppp 对 qqq 充分。
  • 减税 qqq 是当选 ppp 的必要结果；若税收没有降低，即 ¬q\neg q¬q，则可以推出我没有当选，即 ¬p\neg p¬p。

但“税收降低”不能反过来证明“我当选”：别的候选人也可能减税。所以 qqq 对 ppp 是必要条件，不表示 qqq 对 ppp 也充分。课件的政治例子只是用来解释箭头方向；它并没有断言某次真实选举或政策一定如此。

记忆方向时可以问：哪件事一发生就保证另一件事？ 那件事是充分条件；被保证、不可缺少的那件事是必要条件。这个推论依赖 p→qp\to qp→q 作为规则成立，不能仅凭某次两句话碰巧都是真的就断言一般性的保证关系。

英文条件句的不同说法，箭头方向相同

这一页把多种英文表达都翻译成同一逻辑式 p→qp\to qp→q。读句子时先找出“发生什么就足以保证什么”，不要只凭 ppp、qqq 在英语句中的先后位置判断箭头。

英文说法 可理解为
if ppp, then qqq；ppp implies qqq 如果 ppp，那么 qqq；ppp 蕴含 qqq
ppp is a sufficient condition for qqq ppp 是 qqq 的充分条件
ppp only if qqq 只有 qqq 时才可能有 ppp
qqq if ppp；qqq when ppp 在 ppp 成立时，qqq 成立
qqq follows from ppp qqq 可由 ppp 推出
qqq is a necessary condition for ppp qqq 是 ppp 的必要条件

最容易看反的是 “ppp only if qqq”。它说的是：没有 qqq，就不可能有 ppp；即 ¬q→¬p\neg q\to\neg p¬q→¬p。这与 p→qp\to qp→q 方向相同，不是 q→pq\to pq→p。

课件的例子是“公司只有在资金充足时才可能成功”。令 ppp 为“公司成功”，qqq 为“资金充足”，便得到 p→qp\to qp→q：成功需要充足资金。它没有说“有了充足资金就一定成功”；资金充足是这里的必要条件，并未被宣称为充分条件。把每个英文版本都改写为“如果 ppp，那么 qqq”，可以统一检查方向。

原命题、逆命题、否命题与逆否命题

以 p→qp\to qp→q 为原命题，其中 ppp 是“我当选”，qqq 是“税收降低”。课件展示三种改写，它们的箭头方向和否定位置不同：

名称 形式 在本例中的说法
逆否命题（contrapositive） ¬q→¬p\neg q\to\neg p¬q→¬p 如果税收没有降低，那么我没有当选。
逆命题（converse） q→pq\to pq→p 如果税收降低，那么我当选。
否命题（inverse） ¬p→¬q\neg p\to\neg q¬p→¬q 如果我没有当选，那么税收不会降低。

重要结论是：p→qp\to qp→q 与它的逆否命题 ¬q→¬p\neg q\to\neg p¬q→¬p 逻辑等价。 两者都只在 ppp 真、qqq 假时为假：前者是“当选却没减税”，后者在同一情形中是“没减税却当选”。课件下方的真值表也显示两列结果完全相同：T、F、T、T。

逆命题与否命题不能由原命题自动推出。 即使“当选就减税”成立，也可能由其他候选人减税，所以“减税就当选”不一定成立；同理，“未当选就不减税”也不一定成立。逆命题 q→pq\to pq→p 与否命题 ¬p→¬q\neg p\to\neg q¬p→¬q 则互为逆否，因此它们彼此等价。读题时最好先写出 ppp、qqq，再分别移动箭头与否定符号，避免仅凭中文语感判断。

双条件：两边互相保证

双条件命题（biconditional statement）写作 p↔qp\leftrightarrow qp↔q，读作“ppp 当且仅当 qqq”，英文常说 ppp if and only if qqq，缩写为 ppp iff qqq。它把两个方向一起要求：p→qp\to qp→q 且 q→pq\to pq→p。

ppp qqq p↔qp\leftrightarrow qp↔q
T T T
T F F
F T F
F F T

因此，ppp 与 qqq 真值相同时双条件为真，真值不同时为假。最后一行容易忽略：两边都假时，两个方向的条件命题都没有出现“真前提、假结论”的反例，所以 p↔qp\leftrightarrow qp↔q 仍为真。

课件列出的几种说法意思相同：“ppp 当且仅当 qqq”；“ppp 是 qqq 的必要且充分条件”；“如果 ppp 那么 qqq，反过来也一样”。例如，对一个整数 nnn，“nnn 是偶数，当且仅当 nnn 除以 222 余 000”要求两方向都成立：偶数必余 000，余 000 也必为偶数。

检查双条件时，应分别证明或核对两个箭头。只证明 p→qp\to qp→q，不能擅自补上 q→pq\to pq→p。

日常语言里的“如果”可能说得不完整

课件的句子是：“如果你吃完正餐，就可以吃甜点。”设 ppp 为“你吃完正餐”，qqq 为“你获准吃甜点”。按形式逻辑，这句话只写成 p→qp\to qp→q：吃完正餐时，应允许吃甜点。

若你没有吃完正餐，ppp 为假。条件命题 p→qp\to qp→q 此时仍为真，且没有规定 qqq 的真假：规则并未说你一定能吃甜点，也未说你一定不能吃。不能把 p→qp\to qp→q 自动改写成 ¬p→¬q\neg p\to\neg q¬p→¬q。

但在日常对话里，说这句话的人往往想表达更严格的规定：“只有吃完正餐才能吃甜点。”那还需要反方向 q→pq\to pq→p，即“若获准吃甜点，就已经吃完正餐”。两个方向合在一起是 p↔qp\leftrightarrow qp↔q：吃完正餐当且仅当获准吃甜点。在这种更强的规定下，没吃完就不能吃甜点。

这就是课件所说的自然语言歧义（ambiguity）。解题时应根据明确给出的规则翻译；若题意不清，要区分作者只承诺了“充分条件”，还是同时规定了“必要条件”，不能自行把单向箭头补成双向箭头。

检查规则时寻找可能的反例：已封口的信封

这页引入一个信封实验，用来比较人的直觉和命题逻辑。规则是：“如果信封已封口，那么另一面必须有邮票。”令 ppp 表示“信封已封口”，qqq 表示“信封有邮票”，规则就是 p→qp\to qp→q。任务不是把所有信封随意翻一遍，而是用最少翻面次数检查是否存在违反规则的信封。

什么情况能推翻 p→qp\to qp→q？真值表给出的唯一反例是 p∧¬qp\land\neg qp∧¬q：信封已封口，但没有邮票。因此，翻不翻某个信封，应看它的背面是否可能揭示这一组合。

本页先讨论第 1 种情况：你看到一封已封口的信封，已知 ppp 为真，却还不知道 qqq。需要翻过来检查是否有邮票。若背面有邮票，就是 p=T,q=Tp=\mathrm{T},q=\mathrm{T}p=T,q=T，这封信封符合规则；若背面没有邮票，就是 p=T,q=Fp=\mathrm{T},q=\mathrm{F}p=T,q=F，立刻构成反例。

课件说共有四种可见情况，但这一页只分析“已封口”的情况。核心策略是先写清楚规则的真假条件，再只检查那些有可能出现反例的对象。

信封规则的其余三种情况：翻哪两类？

规则仍是 p→qp\to qp→q，其中 ppp 表示“信封已封口”，qqq 表示“信封有邮票”。要找的唯一违规情况是 p∧¬qp\land\neg qp∧¬q。上一页已说明：看到已封口的一面，需要翻过来检查邮票。本页继续分析其余三种可见情况。

2. 看到开口信封：不必翻。 已知 ¬p\neg p¬p。规则只约束已封口的信封，开口信封背面有邮票或没有邮票，都不能构成 p∧¬qp\land\neg qp∧¬q。形式上，前提 ppp 为假时，p→qp\to qp→q 为真。

3. 看到有邮票的信封：不必翻。 已知 qqq 为真。无论背面显示“已封口”还是“开口”，都不会是“已封口且无邮票”的反例。

4. 看到没有邮票的信封：必须翻。 已知 ¬q\neg q¬q，需要确认它是开口的，即 ¬p\neg p¬p；如果背面其实已封口，就发现违反规则的信封。这正对应原规则的逆否命题 ¬q→¬p\neg q\to\neg p¬q→¬p。

因此，为了用最少翻面次数检查规则，应翻看已封口和没有邮票这两类信封；不用翻开口或已有邮票的信封。课件说多数实验参与者在第 4 类上答错，意在指出人的直觉容易只找“支持规则”的例子，却漏掉可能推翻规则的反例。

练习 1 · 2019 Midterm 1(b)

2 分 · 原题 PDF · 第 3 页

Let c,d,rc,d,rc,d,r, and www be the propositiions

ccc: “It is cold”

ddd: “It is dry”

rrr: “It is rainy”

www: “It is windy”

Write the following propositions using c,d,rc,d,rc,d,r and www and the Boolean connectives.

(b) It is rainy if it is not cold.

查看答案与解析

Official Answer

Source: physical PDF page 3.

¬c→r\neg c\to r¬c→r.

Supplementary Explanation

Answer. ¬c→r\neg c\to r¬c→r.

Derivation/proof. A sentence “A if B” means “if B, then A.” Taking A as rainy and B as not cold places ¬c\neg c¬c in the antecedent and rrr in the consequent. It makes no claim about rain when it is cold.

The only falsifying case is not cold and not rainy: ¬c\neg c¬c is then true while rrr is false. This confirms the direction of the implication ¬c→r\neg c\to r¬c→r.

练习 2 · 2019 Midterm 1(c)

2 分 · 原题 PDF · 第 3 页

Let c,d,rc,d,rc,d,r, and www be the propositiions

ccc: “It is cold”

ddd: “It is dry”

rrr: “It is rainy”

www: “It is windy”

Write the following propositions using c,d,rc,d,rc,d,r and www and the Boolean connectives.

(c) To be windy it is necessary that it be cold.

查看答案与解析

Official Answer

Source: physical PDF page 3.

w→cw\to cw→c.

Supplementary Explanation

Answer. w→cw\to cw→c.

Derivation/proof. Cold is necessary for wind, meaning wind cannot occur without cold. Thus every valuation with w=Tw=Tw=T must have c=Tc=Tc=T, exactly the implication w→cw\to cw→c. The equivalent contrapositive is ¬c→¬w\neg c\to\neg w¬c→¬w. Cold alone does not guarantee wind.

The implication permits cold without wind: www false and ccc true still satisfies w→cw\to cw→c. It forbids wind without cold, so reversing the implication would change the statement.

练习 3 · 2019 Midterm 1(d)

2 分 · 原题 PDF · 第 3 页

Let c,d,rc,d,rc,d,r, and www be the propositiions

ccc: “It is cold”

ddd: “It is dry”

rrr: “It is rainy”

www: “It is windy”

Write the following propositions using c,d,rc,d,rc,d,r and www and the Boolean connectives.

(d) It is rainy only if it is windy and cold.

查看答案与解析

Official Answer

Source: physical PDF page 3.

r→(w∧c)r\to(w\land c)r→(w∧c).

Supplementary Explanation

Answer. r→(w∧c)r\to(w\land c)r→(w∧c).

Derivation/proof. “A only if B” makes B necessary for A. Here B itself consists of two simultaneous requirements, windy and cold. Therefore rain implies both www and ccc, expressed as a conjunction inside the consequent. The claim says nothing requiring rain whenever those two conditions hold.

Equivalently, (r→w)∧(r→c)(r\to w)\land(r\to c)(r→w)∧(r→c). When it is not rainy, the sentence imposes no condition on wind or cold.
