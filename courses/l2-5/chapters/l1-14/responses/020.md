# 密钥生成器需要随机性

这一页主要是一张 PuTTY Key Generator 的历史界面截图，正文文字提取只有标题，因此需要看原图才能理解内容。图中正在生成密钥，提示通过在空白区域移动鼠标收集随机性；进度条表示生成过程尚在进行。

下方区分 Generate（生成）、Load（载入）、Save public key（保存公钥）和 Save private key（保存私钥）。这对应前面的公私钥分工：公钥可以分发，私钥需要保密。生成一对密钥与保存它们，是不同操作。

参数区域展示 RSA 等类型选项，以及示例位数 $2048$。截图属于课件的工具示例，不是当前软件界面或实际部署参数建议，也不是要求在你的电脑上生成密钥。

随机性之所以重要，是因为如果不同用户的素数或私密参数可预测，即使后面的数学公式正确，攻击者仍可能猜到秘密。鼠标运动只是截图展示的熵来源方式；不能把“随机地输入某些东西”本身当作完整的安全生成方案。

这页没有新增 RSA 推导，作用是把抽象的密钥材料与实际生成、载入、分别保存公私钥的工作流程联系起来。
