# 公钥与私钥承担不同权限

此前的对称密码由双方共享秘密密钥；加密与解密所需的密钥信息密切关联，知道共同秘密即可参与两种运算。密钥需要预先分发，或借助密钥交换建立。

Public key cryptography（公钥密码）使用 asymmetric（非对称）的密钥结构。每个接收者持有 public key（公钥），可分发给任何人；同时保留 private key（私钥），只供自己使用。

在加密场景中，发送者用接收者的公钥生成密文，接收者用自己的私钥恢复明文。发送者不用先获得接收者的秘密。安全目标是在已知公钥和密文的情况下，仍难以恢复私钥或明文。

“公开”并不意味着可以接受任意人递来的公钥。如果攻击者把自己的公钥冒充接收者的公钥，发送者就可能把信息加密给攻击者。因此公钥可以不保密，但它的身份归属仍需认证。
