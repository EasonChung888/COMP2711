# 密码学要解决什么问题？

Cryptography（密码学）研究怎样通过不安全的通信渠道传送和接收秘密消息。“渠道不安全”意味着第三方可能看到传输内容；目标是即使消息被截获，也不能轻易读出原意。

这一章原标题为 L07: Cryptography，网站按用户指定编号收录为 L1.14。目录分为 Secret Key Cryptography（秘密密钥密码）、Key Exchange（密钥交换）、Public Key Cryptography and RSA（公钥密码与 RSA）。

三者对应不同问题：双方已共享秘密时怎样编码；尚未共享秘密时怎样协商密钥；能否公开加密所需信息，同时保留只有接收者掌握的解密能力。

蓝色第一项表示先研究共享秘密密钥的情况。前面两章的模运算、逆元和整数性质，将成为描述加密与解密函数的工具。Rosen 4.6 是课件列出的阅读章节；本页还没有给出任何具体密码系统的安全证明。
