独立事件：交集概率是否等于乘积

两个事件 EEE、FFF 独立（independent）的定义是

p(E∩F)=p(E)p(F).p(E\cap F)=p(E)p(F).p(E∩F)=p(E)p(F).

这个等式既是独立事件的性质，也是检查独立性的标准。不要只凭“看起来无关”判断；必须依据试验模型或算出两边验证。

以从标准牌组抽两张牌为例，令 EEE 为第一次抽红牌，FFF 为第二次抽红牌。红牌有 26 张。

放回并重新均匀抽取： 每次抽取前牌组都恢复为 52 张，红牌各占一半，

p(E∩F)=26522652=14=p(E)p(F).p(E\cap F)=\frac{26}{52}\frac{26}{52}=\frac14=p(E)p(F).p(E∩F)=5226​5226​=41​=p(E)p(F).

所以两事件独立。

不放回： 两次抽取各自的边际红牌概率仍为 1/21/21/2，但若第一次已抽红牌，余下 51 张中只剩 25 张红牌。因此

p(E∩F)=26522551=25102≠14.p(E\cap F)=\frac{26}{52}\frac{25}{51}=\frac{25}{102}\ne\frac14.p(E∩F)=5226​5125​=10225​=41​.

所以两事件不独立。若第一次抽黑牌，则余下红牌比例是 26/5126/5126/51。这两个不同的条件概率说明第一次结果会改变第二次红牌的机会；不应把第二次无条件概率直接说成 25/5125/5125/51。

独立也不是互斥。互斥表示 E∩F=∅E\cap F=\varnothingE∩F=∅，所以交集概率为 0；若两个事件概率都为正，它们就不可能既互斥又独立，因为乘积大于 0。

在概率乘法中，确认独立后才可以直接乘无条件概率。不放回抽样的逐步乘法使用的是相应条件下的概率，不能混为一谈。

用四位 bit string 验证独立性

均匀随机选择长度为 4 的 bit string，总共有 24=162^4=1624=16 个等可能结果。定义 EEE 为“首位是 1”，FFF 为“1 的个数为偶数”，问它们是否独立。

首位固定为 1，后三位任意，所以 ∣E∣=23=8|E|=2^3=8∣E∣=23=8，

p(E)=816=12.p(E)=\frac8{16}=\frac12.p(E)=168​=21​.

FFF 包括 0 个、2 个或 4 个 1。0 也是偶数，所以全 0 串必须计算在内：

∣F∣=(40)+(42)+(44)=1+6+1=8,|F|=\binom40+\binom42+\binom44=1+6+1=8,∣F∣=(04​)+(24​)+(44​)=1+6+1=8,

因此 p(F)=1/2p(F)=1/2p(F)=1/2。也可通过翻转某一位，把偶数个 1 的串与奇数个 1 的串一一配对。

交集要求首位为 1，同时总共有偶数个 1。后三位必须含奇数个 1，因此完整结果为

E∩F={1111,1100,1010,1001}.E\cap F=\{1111,1100,1010,1001\}.E∩F={1111,1100,1010,1001}.

于是

p(E∩F)=416=14=p(E)p(F).p(E\cap F)=\frac4{16}=\frac14=p(E)p(F).p(E∩F)=164​=41​=p(E)p(F).

所以 EEE 与 FFF 独立。 即使 FFF 的定义涉及首位，它们仍可以独立；不能只根据“两个条件提到了同一部分数据”就断言有关联。

从条件角度看，已知首位为 1 后，八个剩余可能串中恰好四个满足偶数条件，概率仍为 1/21/21/2，没有变化。独立性是关于概率模型的精确关系，应通过等式检验。

两个孩子的例子：包含关系导致不独立

本题采用简化的 B/G 模型：每个孩子分别以 1/21/21/2 概率对应 B 或 G，各孩子结果相互独立。对两个孩子，按出生顺序记录的样本空间是

S={BB,BG,GB,GG},S=\{BB,BG,GB,GG\},S={BB,BG,GB,GG},

四个结果各有 1/41/41/4 概率。不能把 BG 与 GB 合成一个等可能结果，因为它们是两种不同的有序情况。

事件 EEE 为家庭中两种类别都有，故

E={BG,GB},p(E)=12.E=\{BG,GB\},\qquad p(E)=\frac12.E={BG,GB},p(E)=21​.

事件 FFF 为“至多一个男孩”，包含一个或零个男孩：

F={BG,GB,GG},p(F)=34.F=\{BG,GB,GG\},\qquad p(F)=\frac34.F={BG,GB,GG},p(F)=43​.

交集为

E∩F={BG,GB}=E,E\cap F=\{BG,GB\}=E,E∩F={BG,GB}=E,

所以 p(E∩F)=1/2p(E\cap F)=1/2p(E∩F)=1/2，而

p(E)p(F)=12⋅34=38.p(E)p(F)=\frac12\cdot\frac34=\frac38.p(E)p(F)=21​⋅43​=83​.

两者不相等，EEE 与 FFF 不独立。

直观原因是 E⊆FE\subseteq FE⊆F：两个孩子都有 B/G，就必然恰好一个 B，也就必然满足“至多一个 B”。知道 EEE 发生，会使 FFF 的概率从 3/43/43/4 变为 1。

注意题目中的独立层次：各个孩子的结果独立，并不保证由全部孩子结果构成的任意两个事件也独立。必须具体计算事件概率与交集概率。

三个孩子的例子：相同条件可以变得独立

这页沿用各孩子独立、B/G 各概率 1/21/21/2 的模型，但把人数从 2 改为 3。样本空间共有 23=82^3=823=8 个等可能的有序结果。

EEE 表示两种类别都有，即排除 BBB 和 GGG，因此

E={BBG,BGB,BGG,GBB,GBG,GGB},p(E)=68=34.E=\{BBG,BGB,BGG,GBB,GBG,GGB\},\qquad p(E)=\frac68=\frac34.E={BBG,BGB,BGG,GBB,GBG,GGB},p(E)=86​=43​.

FFF 表示至多一个 B，所以

F={BGG,GBG,GGB,GGG},p(F)=48=12.F=\{BGG,GBG,GGB,GGG\},\qquad p(F)=\frac48=\frac12.F={BGG,GBG,GGB,GGG},p(F)=84​=21​.

两条件同时成立时，不能全是 G，又不能超过一个 B，因此必须恰好一个 B：

E∩F={BGG,GBG,GGB},p(E∩F)=38.E\cap F=\{BGG,GBG,GGB\},\qquad p(E\cap F)=\frac38.E∩F={BGG,GBG,GGB},p(E∩F)=83​.

而

p(E)p(F)=34⋅12=38.p(E)p(F)=\frac34\cdot\frac12=\frac38.p(E)p(F)=43​⋅21​=83​.

所以这一次 EEE 与 FFF 独立。

两个孩子时不独立，三个孩子时却独立，说明独立性取决于具体样本空间和概率分布，不能只看事件的文字描述。两事件都涉及所有孩子，也并不阻止它们满足独立等式。

可以进一步检查条件概率：已知 FFF，四个可能结果中有三个满足 EEE，比例仍为 3/43/43/4；已知 EEE，六个可能结果中有三个满足 FFF，比例仍为 1/21/21/2。

本题的独立来自这组计数比例恰好满足定义。改变人数或改变 B/G 概率后，必须重新检验，不能直接沿用结论。

五个孩子的例子：用 bit string 计数

本页把相同模型扩展到五个孩子，仍假设各孩子独立、B/G 各概率 1/21/21/2。用 0 表示 B、1 表示 G，一家人的结果就是长度为 5 的 bit string，共 25=322^5=3225=32 个等可能结果。

EEE 为两种类别都有，只需排除全 0 和全 1 两个串，所以

p(E)=32−232=3032.p(E)=\frac{32-2}{32}=\frac{30}{32}.p(E)=3232−2​=3230​.

FFF 为至多一个 B，即串中至多一个 0。没有 0 有一个串，恰好一个 0 有 (51)=5\binom51=5(15​)=5 个串，因此

p(F)=1+532=632.p(F)=\frac{1+5}{32}=\frac6{32}.p(F)=321+5​=326​.

交集 E∩FE\cap FE∩F 要求两种都有，同时至多一个 0，因此恰好一个 0：

p(E∩F)=532.p(E\cap F)=\frac5{32}.p(E∩F)=325​.

乘积是

p(E)p(F)=3032632=45256,p(E)p(F)=\frac{30}{32}\frac6{32}=\frac{45}{256},p(E)p(F)=3230​326​=25645​,

而 5/32=40/2565/32=40/2565/32=40/256，两者不同。所以 EEE、FFF 不独立。

已知 FFF 时，六个可能结果中有五个属于 EEE，因此 EEE 的条件概率为 5/65/65/6，不同于原先的 30/32=15/1630/32=15/1630/32=15/16。这是另一种核对。

对一般 n≥2n\ge2n≥2，同样的计数给出

p(E)=2n−22n,p(F)=n+12n,p(E∩F)=n2n.p(E)=\frac{2^n-2}{2^n},\quad p(F)=\frac{n+1}{2^n},\quad p(E\cap F)=\frac n{2^n}.p(E)=2n2n−2​,p(F)=2nn+1​,p(E∩F)=2nn​.

是否独立仍须把交集与乘积比较。前两页与本页的结论分别是不独立、独立、不独立，提醒我们不能凭两次例子猜测一般规律。

一般人数的独立性：从概率变成整数方程

这一页问：当 n>3n>3n>3 时，“两种类别都有”事件 EEE 与“至多一个 B”事件 FFF 是否可能独立？仍使用各孩子独立、B/G 各概率 1/21/21/2 的模型。

对 n≥2n\ge2n≥2，长度为 nnn 的 bit string 有 2n2^n2n 个。两种都有需排除全 B 与全 G；至多一个 B 有全 G 的一种与恰好一个 B 的 nnn 种；交集必须恰好一个 B。因此

p(E)=2n−22n,p(F)=n+12n,p(E∩F)=n2n.p(E)=\frac{2^n-2}{2^n},\qquad p(F)=\frac{n+1}{2^n},\qquad p(E\cap F)=\frac n{2^n}.p(E)=2n2n−2​,p(F)=2nn+1​,p(E∩F)=2nn​.

独立性要求交集等于乘积：

n2n=2n−22nn+12n.\frac n{2^n}=\frac{2^n-2}{2^n}\frac{n+1}{2^n}.2nn​=2n2n−2​2nn+1​.

两边乘 22n2^{2n}22n 并整理：

n2n=(2n−2)(n+1)=(n+1)2n−2n−2,2n=2n+2.\begin{aligned} n2^n&=(2^n-2)(n+1)\\ &=(n+1)2^n-2n-2,\\ 2^n&=2n+2. \end{aligned}n2n2n​=(2n−2)(n+1)=(n+1)2n−2n−2,=2n+2.​

n=3n=3n=3 时，8=88=88=8，所以独立；n=4n=4n=4 时，16>1016>1016>10，已经不相等。要证明所有整数 n>3n>3n>3 都不满足，不能只检验几个数，可以使用归纳法。

基例 n=4n=4n=4 已成立。若 2n>2n+22^n>2n+22n>2n+2，则

2n+1>4n+4>2n+4=2(n+1)+22^{n+1}>4n+4>2n+4=2(n+1)+22n+1>4n+4>2n+4=2(n+1)+2

（这里 n>0n>0n>0），因此不等式对下一个人数也成立。于是所有整数 n>3n>3n>3 都有 2n>2n+22^n>2n+22n>2n+2，两个事件都不独立。

课件说方程仅在 n=3n=3n=3 成立，应理解为本题相关的整数范围；在 n≥2n\ge2n≥2 中，n=2n=2n=2 不成立，n=3n=3n=3 成立，更大人数不成立。若额外讨论 n=1n=1n=1，EEE 是不可能事件，FFF 是必然事件，二者也满足独立等式，但本页用于交集的 n/2nn/2^nn/2n 公式此时不适用。

这个例子的完整方法是：建立等可能结果 → 计数事件与交集 → 写独立等式 → 解方程并证明适用范围。

练习 1 · 2017 Final 6(b)

2 分 · Q-2017-FINAL-P06-b · 原题 PDF · 第 10 页

64 fair coins are flipped independently randomly and then arranged in an 8 by 8 block randomly without looking. Each row contains eight coins and there are eight rows. If all eight coins in a row have the same symbol (heads or tails), we call it a homogeneous row. Let XXX denote the number of homogeneous rows in the block.

(b) Calculate p(X=1)p(X=1)p(X=1).

Official Answer

Source: physical PDF page 10.

For any given row, the chance it is homogeneous is (1/2)8⋅2=(1/2)7(1/2)^8\cdot2=(1/2)^7(1/2)8⋅2=(1/2)7 (all heads or all tails). The chance that it is not homogeneous is (1−(1/2)7)(1-(1/2)^7)(1−(1/2)7). Overall, seven rows must not be homogeneous and one row must be homogeneous, so p(X=1)=8(1/2)7(1−(1/2)7)7p(X=1)=8(1/2)^7(1-(1/2)^7)^7p(X=1)=8(1/2)7(1−(1/2)7)7.

Supplementary Explanation

Answer. 8(1/128)(127/128)78(1/128)(127/128)^78(1/128)(127/128)7.

Derivation/proof. A given row is homogeneous in two of its 282^828 equally likely configurations, so its probability is q=2/28=1/128q=2/2^8=1/128q=2/28=1/128. Distinct rows use disjoint independent coins. Choose which of the eight rows succeeds, multiply by qqq for it and (1−q)7(1-q)^7(1−q)7 for the failures. The eight choices are disjoint, giving 8q(1−q)78q(1-q)^78q(1−q)7.

Randomly arranging the coins without observing their faces preserves the independent fair distribution at all sixty-four positions.

A row is homogeneous with probability q=2(1/2)8=1/128q=2(1/2)^8=1/128q=2(1/2)8=1/128, since either all eight coins are heads or all are tails. The independent eight rows then give P(X=1)=8(1/128)(127/128)7P(X=1)=8(1/128)(127/128)^7P(X=1)=8(1/128)(127/128)7 by selecting its unique homogeneous row.
