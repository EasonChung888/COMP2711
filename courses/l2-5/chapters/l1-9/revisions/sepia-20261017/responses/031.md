# 五个孩子时的 bit string 计数

用 0 表示 B、1 表示 G，五个孩子对应五位 bit string。仍假设各孩子独立、B/G 各概率 $1/2$，全部 $2^5=32$ 个串等可能。

事件 $E$ 要求两种类别都有，去掉全 0、全 1 即可。$F$ 要求至多一个 B，也就是零个或一个 0：

$$p(E)=\frac{32-2}{32}=\frac{30}{32},\qquad
p(F)=\frac{1+\binom51}{32}=\frac6{32}.$$

同时满足两条件，就必须恰好有一个 0，因此

$$p(E\cap F)=\frac5{32}=\frac{40}{256},\qquad
p(E)p(F)=\frac{30}{32}\frac6{32}=\frac{45}{256}.$$

两数不等，所以不独立。给定 $F$，六个结果中五个满足 $E$，概率为 $5/6$，也确实不同于原来的 $30/32=15/16$。

同样的计数对一般 $n\ge2$ 给出

$$p(E)=\frac{2^n-2}{2^n},\quad
p(F)=\frac{n+1}{2^n},\quad
p(E\cap F)=\frac n{2^n}.$$

比较交集与乘积才能判断独立性。前面的 $n=2$ 不独立，$n=3$ 独立，本页 $n=5$ 又不独立。
