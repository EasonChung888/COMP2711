# 十位 bit string 中至少一个 0

从全部长度为 10 的 bit string 中均匀选一个，共有 $2^{10}=1024$ 个等可能结果。令 $E$ 表示“至少有一位是 0”。只有串 1111111111 不满足条件，因此

$$p(E)=1-p(\overline E)=1-\frac1{2^{10}}=\frac{1023}{1024}.$$

直接计数也能做。“至少一个 0”包括恰好 1 个、2 个，直到 10 个 0 的情况：

$$\binom{10}{1}+\binom{10}{2}+\cdots+\binom{10}{10}=2^{10}-1.$$

取补只需去掉一个全 1 串，计算短得多。

若把“第 1 位为 0”“第 2 位为 0”等十个事件的概率直接相加，就会得到 $10\times1/2=5$。一个含多个 0 的串会被数好几次，而且 5 已超过概率的上限。

均匀选择整个串，等价于十个位相互独立，且各位 0、1 的概率各为 $1/2$。若各位有偏或相关，$2^{10}$ 个串未必等可能；“至少一个 0 = 1 − 全部为 1 的概率”仍然成立，只需按新模型计算右侧。
