五个孩子的例子：用 bit string 计数

本页把相同模型扩展到五个孩子，仍假设各孩子独立、B/G 各概率 1/21/21/2。用 0 表示 B、1 表示 G，一家人的结果就是长度为 5 的 bit string，共 25=322^5=3225=32 个等可能结果。

EEE 为两种类别都有，只需排除全 0 和全 1 两个串，所以

p(E)=32−232=3032.p(E)=\frac{32-2}{32}=\frac{30}{32}.p(E)=3232−2​=3230​.

FFF 为至多一个 B，即串中至多一个 0。没有 0 有一个串，恰好一个 0 有 (51)=5\binom51=5(15​)=5 个串，因此

p(F)=1+532=632.p(F)=\frac{1+5}{32}=\frac6{32}.p(F)=321+5​=326​.

交集 E∩FE\cap FE∩F 要求两种都有，同时至多一个 0，因此恰好一个 0：

p(E∩F)=532.p(E\cap F)=\frac5{32}.p(E∩F)=325​.

乘积是

p(E)p(F)=3032632=45256,p(E)p(F)=\frac{30}{32}\frac6{32}=\frac{45}{256},p(E)p(F)=3230​326​=25645​,

而 5/32=40/2565/32=40/2565/32=40/256，两者不同。所以 EEE、FFF 不独立。

已知 FFF 时，六个可能结果中有五个属于 EEE，因此 EEE 的条件概率为 5/65/65/6，不同于原先的 30/32=15/1630/32=15/1630/32=15/16。这是另一种核对。

对一般 n≥2n\ge2n≥2，同样的计数给出

p(E)=2n−22n,p(F)=n+12n,p(E∩F)=n2n.p(E)=\frac{2^n-2}{2^n},\quad p(F)=\frac{n+1}{2^n},\quad p(E\cap F)=\frac n{2^n}.p(E)=2n2n−2​,p(F)=2nn+1​,p(E∩F)=2nn​.

是否独立仍须把交集与乘积比较。前两页与本页的结论分别是不独立、独立、不独立，提醒我们不能凭两次例子猜测一般规律。
