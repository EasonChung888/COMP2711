# 五个孩子的例子：用 bit string 计数

本页把相同模型扩展到五个孩子，仍假设各孩子独立、B/G 各概率 $1/2$。用 0 表示 B、1 表示 G，一家人的结果就是长度为 5 的 bit string，共 $2^5=32$ 个等可能结果。

$E$ 为两种类别都有，只需排除全 0 和全 1 两个串，所以

$$p(E)=\frac{32-2}{32}=\frac{30}{32}.$$

$F$ 为至多一个 B，即串中至多一个 0。没有 0 有一个串，恰好一个 0 有 $\binom51=5$ 个串，因此

$$p(F)=\frac{1+5}{32}=\frac6{32}.$$

交集 $E\cap F$ 要求两种都有，同时至多一个 0，因此恰好一个 0：

$$p(E\cap F)=\frac5{32}.$$

乘积是

$$p(E)p(F)=\frac{30}{32}\frac6{32}=\frac{45}{256},$$

而 $5/32=40/256$，两者不同。所以 **$E$、$F$ 不独立**。

已知 $F$ 时，六个可能结果中有五个属于 $E$，因此 $E$ 的条件概率为 $5/6$，不同于原先的 $30/32=15/16$。这是另一种核对。

对一般 $n\ge2$，同样的计数给出

$$p(E)=\frac{2^n-2}{2^n},\quad p(F)=\frac{n+1}{2^n},\quad p(E\cap F)=\frac n{2^n}.$$

是否独立仍须把交集与乘积比较。前两页与本页的结论分别是不独立、独立、不独立，提醒我们不能凭两次例子猜测一般规律。
