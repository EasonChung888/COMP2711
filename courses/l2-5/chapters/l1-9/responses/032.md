# 一般人数的独立性：从概率变成整数方程

这一页问：当 $n>3$ 时，“两种类别都有”事件 $E$ 与“至多一个 B”事件 $F$ 是否可能独立？仍使用各孩子独立、B/G 各概率 $1/2$ 的模型。

对 $n\ge2$，长度为 $n$ 的 bit string 有 $2^n$ 个。两种都有需排除全 B 与全 G；至多一个 B 有全 G 的一种与恰好一个 B 的 $n$ 种；交集必须恰好一个 B。因此

$$p(E)=\frac{2^n-2}{2^n},\qquad p(F)=\frac{n+1}{2^n},\qquad p(E\cap F)=\frac n{2^n}.$$

独立性要求交集等于乘积：

$$\frac n{2^n}=\frac{2^n-2}{2^n}\frac{n+1}{2^n}.$$

两边乘 $2^{2n}$ 并整理：

$$\begin{aligned}
n2^n&=(2^n-2)(n+1)\\
&=(n+1)2^n-2n-2,\\
2^n&=2n+2.
\end{aligned}$$

$n=3$ 时，$8=8$，所以独立；$n=4$ 时，$16>10$，已经不相等。要证明**所有**整数 $n>3$ 都不满足，不能只检验几个数，可以使用归纳法。

基例 $n=4$ 已成立。若 $2^n>2n+2$，则

$$2^{n+1}>4n+4>2n+4=2(n+1)+2$$

（这里 $n>0$），因此不等式对下一个人数也成立。于是所有整数 $n>3$ 都有 $2^n>2n+2$，两个事件都不独立。

课件说方程仅在 $n=3$ 成立，应理解为本题相关的整数范围；在 $n\ge2$ 中，$n=2$ 不成立，$n=3$ 成立，更大人数不成立。若额外讨论 $n=1$，$E$ 是不可能事件，$F$ 是必然事件，二者也满足独立等式，但本页用于交集的 $n/2^n$ 公式此时不适用。

这个例子的完整方法是：建立等可能结果 → 计数事件与交集 → 写独立等式 → 解方程并证明适用范围。
