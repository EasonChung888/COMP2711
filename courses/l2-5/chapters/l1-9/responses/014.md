# 至少一个 0：用补事件避免分类

题目从所有长度为 10 的 bit string 中均匀随机选一个，问“至少有一位是 0”的概率。

每个位置可以是 0 或 1，因此样本空间有

$$|S|=2^{10}=1024$$

个等可能的串。事件 $E$ 是至少含一个 0；它的补事件 $\overline E$ 是**没有任何 0，即十位全部为 1**。

补事件只含一个串：1111111111。因此

$$p(\overline E)=\frac1{2^{10}},$$

所以

$$p(E)=1-p(\overline E)=1-\frac1{1024}=\frac{1023}{1024}.$$

“至少一个 0”包含恰好 1 个、2 个，直到 10 个 0。如果直接计数，需要相加

$$\binom{10}{1}+\binom{10}{2}+\cdots+\binom{10}{10}=2^{10}-1.$$

这也是正确方法，但补事件只用排除唯一的全 1 串，计算更短。

不能用 $10\times1/2$ 计算概率，因为“第 1 位为 0”“第 2 位为 0”等事件相互重叠，多个 0 的串会被重复计算，而且结果 5 已超过概率上限。

均匀随机选择 bit string 等价于各位独立且 0、1 各概率 $1/2$ 的模型。若各位有偏或相关，不能只用 $2^{10}$ 作等可能分母，但“至少一个 0 = 1 − 全部为 1 的概率”的关系仍成立。
