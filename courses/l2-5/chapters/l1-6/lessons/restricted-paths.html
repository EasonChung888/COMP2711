网格路径与指定边

图中取 A 为 (0,0)(0,0)(0,0)，B 为 (6,4)(6,4)(6,4)，每步只能向右 R 或向上 U。C 为 (5,1)(5,1)(5,1)，D 为 (5,2)(5,2)(5,2)，CD 是一条向上的指定边。

没有限制：必须走六步 R、四步 U，共十步。路径唯一对应其步序，选出四个 U 的位置即可：

C(10,4)=210.C(10,4)=210.C(10,4)=210.

必须经过 CD：路径唯一拆成 A→C、固定的 C→D、D→B 三部分。A→C 需五右一上，有 C(6,1)=6C(6,1)=6C(6,1)=6 条；D→B 需一右两上，有 C(3,1)=3C(3,1)=3C(3,1)=3 条。中间指定边只有一种，所以

6⋅1⋅3=18.6\cdot1\cdot3=18.6⋅1⋅3=18.

不能经过 CD：从全部路径减去经过指定边的路径：

210−18=192.210-18=192.210−18=192.

路径数使用组合，是因为每类步子相同，但它们在步序中的位置不同。只选 U 的位置就唯一确定完整路径，不需要再排列四个 U。

经过 C 并不等于经过 CD；从 C 向右也可能最终到 B。必须将指定边单独纳入分段，才能满足本题真正的限制。

三行点阵中的斜向路径

图中只能向右上或右下移动一步，且只能走图中三行点阵内的相邻点。A、B 都在最下行，左端到右端共需八步。

从 A 出发第一步只能到中间行的 X；到 B 的最后一步也被终点确定。由于每一步上下移动一行，且不能离开三行点阵，之后每隔一列都必须回到中间行。图中红圈标出四个这样的必经点。

相邻红圈之间有两步，两种选择：先上再下，经上方点；或先下再上，经下方点。四个红圈形成三个可自由选择的区段，因此无额外限制时有

1⋅23⋅1=81\cdot2^3\cdot1=81⋅23⋅1=8

条路径。首尾的两段各只有一种，不再产生因子 2。

若必须经过上方的 C，三个自由区段中间的一个被固定为上方路线，其余两个仍可任选，所以有 22=42^2=422=4 条。也可按 C 分段：A→C 两种，C→B 两种，乘得 2⋅2=42\cdot2=42⋅2=4。

不能只选八步中哪些向上而忽略点阵边界：那会把越过最上行或最下行的路线算入。先找必经点和独立分段，才能准确使用乘法法则。

练习 1 · 2018 Final 11(b)

Q-2018-FINAL-P11-b · 原题 PDF · 第 16 页

In the following shape, consider paths that start from AAA and finish at BBB following the lines. Every path may only have steps going up or right. E.g., one path would be {↑,↑,↑,→,→,→,→,→}\{\uparrow,\uparrow,\uparrow,\rightarrow,\rightarrow,\rightarrow,\rightarrow,\rightarrow\}{↑,↑,↑,→,→,→,→,→}. How many distinct such paths are there if:

b) The line from C to D (the dashed line in the figure below) is missing, so paths cannot pass between C and D?

查看答案与解析

Official Answer

Source: physical PDF page 16.

Having removed this edge, it is no longer possible to reach DDD from CCC, since down movements are not possible. Therefore, we need to subtract from the total number of paths, those that go through both CCC and DDD. There are C(4,2)=6C(4,2)=6C(4,2)=6 paths from AAA to CCC, 111 path from CCC to DDD, and C(3,2)C(3,2)C(3,2) from DDD to BBB, which means there are 6×1×36\times1\times36×1×3 paths from AAA to BBB that pass through CCC and DDD. So there are 56−18=3856-18=3856−18=38 from AAA to BBB that don't pass between use the edge between CCC and DDD.

Supplementary Explanation

Answer. 56−6⋅1⋅3=3856-6\cdot1\cdot3=3856−6⋅1⋅3=38.

Derivation/proof. Count paths using the missing edge and subtract. Reaching CCC requires two right and two up steps, giving (42)=6\binom42=6(24​)=6 prefixes. The step C→DC\to DC→D is forced. From DDD to BBB, two right and one up step give (32)=3\binom32=3(23​)=3 suffixes. Every forbidden path has this unique decomposition and cannot use the edge twice, so there are 18 forbidden paths. Subtracting from 56 gives 38; a grid dynamic-programming count independently agrees.

A monotone path cannot traverse the forbidden edge twice, so the prefix-edge-suffix count has no duplicate paths.

Every path through the forbidden point splits uniquely into a prefix reaching it and a suffix leaving it. Subtracting those eighteen paths from all fifty-six gives 56−18=3856-18=3856−18=38 valid paths.

练习 2 · 2020 Final Part 1 3(b)

3 分 · Q-2020-FINAL1-P03-b · 原题 PDF · 第 2 页

You are staying on point A and you are allowed to walk either up or to the right. Answer these questions:

In how many ways you can go to point B without passing through point C?

查看答案与解析

Official Answer

Source: physical PDF page 2.

(115)−(63)⋅(53)\binom{11}{5}-\binom63\cdot\binom53(511​)−(36​)⋅(35​).

Supplementary Explanation

Answer. (115)−(63)(53)=262\binom{11}{5}-\binom{6}{3}\binom{5}{3}=262(511​)−(36​)(35​)=262.

Derivation/proof. There are (115)=462\binom{11}{5}=462(511​)=462 unrestricted paths. From A to C the figure requires three right and three up moves, giving (63)=20\binom63=20(36​)=20 prefixes. From C to B it requires three right and two up moves, giving (53)=10\binom53=10(35​)=10 suffixes. A path through C uniquely decomposes into one prefix and one suffix, so exactly 200 pass through C. Subtracting leaves 262.

All paths number 462, and the forbidden-point paths number 200 by the unique prefix/suffix split. Their difference is 462−200=262462-200=262462−200=262.

练习 3 · 2024 Spring Final 4

10 分 · Q-2024S-FINAL-P04 · 原题 PDF · 第 4 页

You want to walk from the point (0,0)(0,0)(0,0) to the point (8,8)(8,8)(8,8) on a square grid, where each point on the grid has integer coordinates. In each step, you can move from a point (i,j)(i,j)(i,j) to either (i+1,j)(i+1,j)(i+1,j) or (i,j+1)(i,j+1)(i,j+1), which means you can move one unit in the positive x-direction or one unit in the positive y-direction, respectively. The walk will take exactly 16 unit steps in total. Additionally, your path must include the grid position (2,3)(2,3)(2,3) and you must avoid the grid position (6,5)(6,5)(6,5). How many different paths can you take from (0,0)(0,0)(0,0) to (8,8)(8,8)(8,8) while satisfying these conditions?

Official Answer

Source: physical PDF page 4, physical PDF page 5.

Answer: We say that a path is monotonic if at each step it either moves one unit in the positive x-direction or one unit in the positive y-direction. Let PPP be a path satisfying the requirements of the problem. Since it must include the point (2,3)(2,3)(2,3), we can decompose PPP into two monotonic paths P1P_1P1​ and P2P_2P2​ as follows:

(0,0)→⋯→(2,3)⏟P1→⋯→(8,8)⏟P2.\underbrace{(0,0)\to\cdots\to(2,3)}_{P_1}\underbrace{\to\cdots\to(8,8)}_{P_2}.P1​(0,0)→⋯→(2,3)​​P2​→⋯→(8,8)​​.

Our answer will be #P1⋅#P2\#P_1\cdot\#P_2#P1​⋅#P2​, where #P1\#P_1#P1​ (#P2\#P_2#P2​) is the number of possibilities for P1P_1P1​ (P2P_2P2​). It is clear that the requirement of PPP avoiding (6,5)(6,5)(6,5) only restricts the possibilities for P2P_2P2​ but not P1P_1P1​. Thus, #P1\#P_1#P1​ is simply the number of all monotonic paths from (0,0)(0,0)(0,0) to (2,3)(2,3)(2,3), which is given by (2+32)=(52)\binom{2+3}{2}=\binom52(22+3​)=(25​). We can count #P2\#P_2#P2​ as #P2=#P2,all−#P2,bad\#P_2=\#P_{2,\mathrm{all}}-\#P_{2,\mathrm{bad}}#P2​=#P2,all​−#P2,bad​ where #P2,all\#P_{2,\mathrm{all}}#P2,all​ is the number of all monotonic paths from (2,3)(2,3)(2,3) to (8,8)(8,8)(8,8) and #P2,bad\#P_{2,\mathrm{bad}}#P2,bad​ is the number of ‘bad’ monotonic paths from (2,3)(2,3)(2,3) to (8,8)(8,8)(8,8) that go through (6,5)(6,5)(6,5). Using the same reasoning for counting #P1\#P_1#P1​, we get that:

#P2,all=((8−2)+(8−3)8−2)=(116).\#P_{2,\mathrm{all}}=\binom{(8-2)+(8-3)}{8-2}=\binom{11}6.#P2,all​=(8−2(8−2)+(8−3)​)=(611​).

Similar to PPP, the paths counted by #P2,bad\#P_{2,\mathrm{bad}}#P2,bad​ have the form:

(2,3)→⋯→(6,5)⏟P3→⋯→(8,8)⏟P4,\underbrace{(2,3)\to\cdots\to(6,5)}_{P_3}\underbrace{\to\cdots\to(8,8)}_{P_4},P3​(2,3)→⋯→(6,5)​​P4​→⋯→(8,8)​​,

where P3P_3P3​ and P4P_4P4​ are monotonic paths. The number of possibilities for P3P_3P3​ is ((6−2)+(5−3)6−2)=(64)\binom{(6-2)+(5-3)}{6-2}=\binom64(6−2(6−2)+(5−3)​)=(46​), and the number of possibilities for P4P_4P4​ is ((8−6)+(8−5)8−6)=(52)\binom{(8-6)+(8-5)}{8-6}=\binom52(8−6(8−6)+(8−5)​)=(25​). Overall, we get that #P2,bad=(116)−(64)⋅(52)\#P_{2,\mathrm{bad}}=\binom{11}6-\binom64\cdot\binom52#P2,bad​=(611​)−(46​)⋅(25​), which implies that our final answer is: (52)⋅[(116)−(64)⋅(52)]\binom52\cdot\left[\binom{11}6-\binom64\cdot\binom52\right](25​)⋅[(611​)−(46​)⋅(25​)].

Supplementary Explanation

Answer. (52)[(116)−(64)(52)]=3120\binom52[\binom{11}6-\binom64\binom52]=3120(25​)[(611​)−(46​)(25​)]=3120.

Derivation/proof. From (0,0)(0,0)(0,0) to (2,3)(2,3)(2,3) there are two right steps and three up steps, giving (52)=10\binom52=10(25​)=10 paths. The unique decomposition at each specified point prevents duplication or omission.
