# 五局三胜：用位串编码停止后的比赛

两队 A、B 比赛，先胜三场者夺冠，立即停止，没有平局。用 1 表示 A 胜、0 表示 B 胜，实际比赛长度为 3、4 或 5。

若 A 在第 $m$ 场夺冠，最后一位必为 1，前 $m-1$ 场恰有两个 1。因此 A 夺冠的实际序列数为
$$C(2,2)+C(3,2)+C(4,2)=1+3+6=10.$$

课件直接写 $C(5,3)=10$，其中需要补充一个编码规则：将 A 夺冠的实际序列**在末尾补 0 到长度 5**。例如 111 编为 11100，1101 编为 11010。补的 0 只是编码，并非继续比赛。

反过来，给定一个长度五且恰有三个 1 的位串，在第三个 1 处截断，即恢复 A 夺冠序列。位串总共只有两个 0，故 B 不会先胜三场。该规则可逆，所以这十种编码与实际结果一一对应。

B 夺冠同理：末尾补 1 到五位，得到恰有三个 0 的十种编码。两队夺冠互斥，总结果数为 $10+10=20$。

停止条件非常重要；不能把任意五场序列都当作实际比赛。课件的组合数计法成立，依靠的是上述双射。
