# 四种基本模型的公式对照

本页把“是否关心次序”与“是否允许重复”两个判断组合起来。$n$ 表示可选元素或类型数，$r$ 表示选择次数或总数。

| 结果模型 | 允许重复？ | 数量 |
|---|---|---|
| 有序选择，$r$ 元排列 | 否 | $P(n,r)=n!/(n-r)!$ |
| 无序选择，$r$ 元组合 | 否 | $C(n,r)=n!/[r!(n-r)!]$ |
| 有序选择 | 是 | $n^r$ |
| 无序重复组合 | 是 | $C(n+r-1,r)$ |

不重复排列的选择数每步减一；不重复组合进一步去掉成员的 $r!$ 种次序。允许重复的有序选择每一步始终有 $n$ 种，因此是 $n^r$。无序重复组合只记录每类数量，用星号隔板计数。

例如从三种字母中取两个：不重复有序为 6，无序为 3；允许重复有序为 9，无序为 6。允许重复的无序结果包括 AA、BB、CC、AB、AC、BC。

前两行要求 $0\le r\le n$；最后一行通常要求 $n\ge1$。允许重复不代表把所有序列简单除以 $r!$，因为重复元素会使不同组合的可见次序数不同。

若另有相邻、首位、库存或停止条件，应先处理限制，再使用相应基本模型。
