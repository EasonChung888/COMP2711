Problem 6: GCD [12 pts] Calculate gcd(2100 −1,265 −1).
Answer: In fact, for any a,m,n, we can apply the Euclidean algorithm:
gcd(am −1,an −1) = gcd(am −an,an −1) = gcd(an(am−n −1),an −1)
Writing am −an as an(am−n, we have
gcd(am −1,an −1) = gcd(an(am−n −1),an −1)
Since gcd(an,an −1) = 1, we get:
gcd(am −1,an −1) = gcd(am−n −1,an −1).
