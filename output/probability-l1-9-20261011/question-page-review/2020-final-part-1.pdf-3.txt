(a) (3 pts) n is divisible by 2, 3 or 5?
(b) (4 pts) n ≡ 1 (mod 2), n ≡ 2 (mod 3), and n ≡ 3 (mod 5)?
(c) (7 pts) n is divisible by 9 but it has no digit 9?
Solution: (a) Let f(k) be the number of integers 0 ≤ n < 1000 that are divided
by k, then f(k) = 1 + ⌊999/k⌋. We have f(2) = 500, f(3) = 334,
f(5) = 200, f(6) = 167, f(10) = 100, f(15) = 67 and f(30) = 34. By
inclusion-exclusion principle, the answer is f(2) +f(3) +f(5) − f(6) −
f(10) − f(15) + f(30) = 734.
(b) By Chinese remainder theorem, we know that n ≡ 1 (mod 2), n ≡ 2
(mod 3), and n ≡ 3 (mod 5) is equivalent to n = 23 + 30 k for an
integer k. Since 0 ≤ n < 1000, we have 0 ≤ k ≤ 32. Therefore the
answer is 33.
(c) Let n = 100 x1 + 10x2 + x3, i.e. n is represented by 3 digits ¯x1x2x3.

x1 + x2 + x3 = 0, 9 or 18.
