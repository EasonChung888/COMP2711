About 18 minutes · Propositional inference

Build a valid argument one justified line at a time

A derivation is not a lucky jump to the answer. It is a chain in which every new line is licensed by a premise, an equivalence, or a rule of inference.

← Lesson 10 Inference reference Lesson 12 →

Your concrete goal

Given propositional premises and a target conclusion, you will be able to choose and cite the eight lecture rules, write a numbered derivation, and disprove an invalid argument with one truth assignment.

Plain-English intuition: treat the conclusion as a destination

First circle the conclusion. Ask, “Which rule could produce its outermost connective?” To produce a ∧ b, you will probably need Conjunction; to produce one side of an existing conjunction, use Simplification. Then scan the premises for the inputs that rule needs.

The line-by-line test: if a reader covers every later line, can they reconstruct this line from the cited earlier lines alone? If yes, the step is justified.

Formal lecture definition and the eight rules

An argument is a sequence of propositions: all but the last are premises, and the final proposition is the conclusion. It is valid exactly when it is impossible for all premises to be true and the conclusion false.

RuleInputsLicensed outputHow to see it
Modus Ponens (MP)p, p → qqThe condition happened, so its consequence follows.
Modus Tollens (MT)¬q, p → q¬pThe consequence failed, so the condition could not hold.
Hypothetical Syllogism (HS)p → q, q → rp → rChain two matching implications.
Disjunctive Syllogism (DS)p ∨ q, ¬pqOne option is eliminated.
Addition (Add)pp ∨ qA true disjunction needs only one true side.
Simplification (Simp)p ∧ qpA true conjunction makes each part true.
Conjunction (Conj)p, qp ∧ qJoin two separately established facts.
Resolution (Res)p ∨ q, ¬p ∨ rq ∨ rResolve the complementary pair p, ¬p.

Logical equivalences may also rewrite a line. A rewrite preserves meaning; an inference rule derives a consequence. Keep those reasons distinct.

Worked example 1: work backward from the target

Premises: ¬q, p → q, ¬p → (r ∧ s). Target: r.

  1. ¬q Premise
  2. p → q Premise
  3. ¬p 1, 2 by Modus Tollens: the failed consequence ¬q rejects p.
  4. ¬p → (r ∧ s) Premise
  5. r ∧ s 3, 4 by Modus Ponens: line 3 supplies the antecedent of line 4.
  6. r 5 by Simplification: the target is one half of the conjunction.

Past-paper model: 2015 Midterm, Problem 2(b), 4 marks. The key planning move is to notice that r can come from simplifying r ∧ s.

Worked example 2: equivalence can expose a rule

Premises: (p ∧ q) ∨ r and r → s. Target: p ∨ s.

  1. (p ∧ q) ∨ r Premise
  2. r → s Premise
  3. ¬r ∨ s 2, implication equivalence: r → s ≡ ¬r ∨ s.
  4. (p ∧ q) ∨ s 1, 3 by Resolution on r and ¬r.
  5. (p ∨ s) ∧ (q ∨ s) 4, distributive equivalence.
  6. p ∨ s 5 by Simplification.

This is the lecture’s page 9 derivation. Resolution did not apply to line 2 until the implication was rewritten as a disjunction.

Invalid arguments: one counterexample is decisive

Consider premises p → r, q → r, and ¬(p ∨ q), with proposed conclusion ¬r. Set p = F, q = F, r = T. Both implications are true, the third premise is true, but ¬r is false. Therefore the argument is invalid.

Do not say only “I cannot find a derivation.” Failure to find one is not proof of invalidity. Give an assignment making every premise true and the conclusion false.

Common mistakes

  • Affirming the consequent: from p → q and q, concluding p. This is not a lecture rule.
  • Denying the antecedent: from p → q and ¬p, concluding ¬q. Also invalid.
  • Skipping the exact line: citing a conjunction when the rule needs one conjunct. Write the Simplification step first.
  • Resolving non-complements: Resolution removes p only against ¬p, never against a merely different proposition.

Two short checks

Check 1. From u ∨ v and ¬u, which rule derives v?

Hint

One side of a disjunction has been eliminated.

Check 2. Write the derivation

Premises: s → r, p ∧ q, p → ¬(q ∧ r). Conclusion: ¬s.

Number every line and cite every reason. This is adapted from 2015 Midterm Problem 2(c), an original 4-mark part.

Hint

Simplify p ∧ q. Use p to obtain ¬(q ∧ r), rewrite it, eliminate ¬q, then use Modus Tollens.

Worked answer - open only after trying
  1. p ∧ q Premise
  2. p 1, Simplification
  3. q 1, Simplification
  4. p → ¬(q ∧ r) Premise
  5. ¬(q ∧ r) 2, 4, Modus Ponens
  6. ¬q ∨ ¬r 5, De Morgan equivalence
  7. ¬r 3, 6, Disjunctive Syllogism
  8. s → r Premise
  9. ¬s 7, 8, Modus Tollens

Takeaway

Start from the target’s shape, expose usable forms with equivalences, and justify exactly one legal move per line.
