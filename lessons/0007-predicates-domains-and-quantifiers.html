About 15 minutes · Predicate logic begins

Turn an open sentence into a claim you can judge

A predicate is a sentence with a blank. A value or a quantifier fills the blank, and the domain tells us which values are allowed.

Your concrete goal

By the end, you can distinguish a predicate from a proposition, explain why the domain matters, and decide a finite universal or existential statement by finding a counterexample or a witness.

Plain-English intuition: a sentence with a slot

P(x): “x is greater than 3” is not yet true or false: we do not know what x is. It is a predicate, like a sentence with an empty slot.

Fill the slot

P(5) means “5 is greater than 3.” It is a true proposition.

Quantify the slot

∀x P(x) checks every allowed x; ∃x P(x) looks for at least one.

Two search modes: to refute ∀, find one counterexample. To establish ∃, find one witness.

Formal lecture definitions

Predicate
P(x₁, …, xₙ) is a statement whose truth value depends on its variables. Assigning all variables produces a proposition.
Domain (or universe)
The set of all values that a variable may take. The same symbols can have different truth values under different domains.
Universal quantification
∀x P(x): “for every x in the domain, P(x) is true.”
Existential quantification
∃x P(x): “there is at least one x in the domain for which P(x) is true.”

For a finite domain D = {a, b, c}:

∀x P(x) ≡ P(a) ∧ P(b) ∧ P(c)

∃x P(x) ≡ P(a) ∨ P(b) ∨ P(c)

The lecture normally assumes the domain is nonempty. Empty-domain behavior is therefore not part of the core course.

Worked example 1: scan a finite domain

Let D = {−1, 0, 2} and P(x): x² > 0.

  1. P(−1) is true because (−1)² = 1 > 0.
  2. P(0) is false because 0² = 0, not greater than 0.
  3. P(2) is true because 2² = 4 > 0.
  4. ∀x P(x) is false: x = 0 is one counterexample.
  5. ∃x P(x) is true: x = −1 is one witness.

Likely beginner error: counting two true cases and calling the universal statement “mostly true.” Universal means every case; one failure is enough.

Worked example 2: changing the domain changes the claim

Consider ∀x (x² ≥ x).

  1. Over the integers, x² − x = x(x − 1). This is nonnegative for every integer x, so the statement is true.
  2. Over the reals, choose x = 1/2. Then x² = 1/4 < 1/2 = x.
  3. Therefore the same written formula is false over the reals.

The formula did not change; the allowed values did. Always write the domain before reasoning.

Common mistakes

  • No domain: ∀x(x² ≥ x) is incomplete until the allowed values are known.
  • One example “proves” every: a witness proves an existential claim, not a universal one.
  • Existence means uniqueness: ∃x means one or more, not exactly one.
  • An open predicate is given a truth value: x > 3 cannot be judged until x is assigned or bound.

Two short checks

Check 1

Let P(x): x + 1 > x. Which expression is a proposition without needing a domain for a quantifier?

Hint

Look for the expression in which no variable is left as an empty slot.

Check 2

If D = {1, 3}, which is exactly equivalent to ∀x P(x)?

Hint

Universal quantification behaves like a large conjunction over a finite domain.

Stretch only: how “exactly one” is different

∃x P(x) only asserts existence. Unique existence can be written as:

∃x(P(x) ∧ ∀y(P(y) → y = x))

The first part finds a witness. The second says that every other possible witness must equal it. This is useful later, but it is not required before Lesson 8.

Takeaway

∀ searches for a counterexample; ∃ searches for a witness - always inside a stated domain.
