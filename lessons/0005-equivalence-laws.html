Lesson 5

Rewrite without changing meaning

Equivalence laws replace one expression by another that has the same truth value in every possible assignment.

Day 15 of 618 minutes

Concrete goal

Use named propositional equivalence laws one step at a time, especially implication, De Morgan, double negation, distributive, negation, identity, and domination laws.

Treat every law as a safe rewrite

If A ≡ B, you may replace A by B inside a larger formula. The symbol ≡ reports logical equivalence; it is not a connective inside a proposition. Work locally: find one matching pattern, rewrite it, and name the law.

High-yield lecture laws

LawSafe rewrite
Implicationp → q ≡ ¬p ∨ q
Contrapositivep → q ≡ ¬q → ¬p
De Morgan¬(p ∧ q) ≡ ¬p ∨ ¬q; ¬(p ∨ q) ≡ ¬p ∧ ¬q
Double negation¬¬p ≡ p
Negationp ∨ ¬p ≡ T; p ∧ ¬p ≡ F
Identity / dominationp ∨ F ≡ p; p ∨ T ≡ T

The lecture reference also includes idempotent, commutative, associative, distributive, absorption, conditional, and biconditional laws.

Worked example 1: negate an implication

Show that ¬(p → q) ≡ p ∧ ¬q.

  1. ¬(p → q) ≡ ¬(¬p ∨ q) — implication law; eliminate the arrow first.
  2. ≡ ¬¬p ∧ ¬q — De Morgan’s law; negate both parts and change ∨ to ∧.
  3. ≡ p ∧ ¬q — double negation.

Likely error: writing ¬p ∧ ¬q. The first input to De Morgan is already ¬p, so negating it produces p.

Worked example 2: a longer chain

Lecture example: simplify ¬(p ∨ (¬p ∧ q)).

  1. ¬(p ∨ (¬p ∧ q)) ≡ ¬p ∧ ¬(¬p ∧ q) — De Morgan.
  2. ≡ ¬p ∧ (p ∨ ¬q) — De Morgan, then double negation.
  3. ≡ (¬p ∧ p) ∨ (¬p ∧ ¬q) — distributive law.
  4. ≡ F ∨ (¬p ∧ ¬q) — negation law.
  5. ≡ ¬p ∧ ¬q — identity law.

Common mistakes

  • Changing two parts at once and being unable to justify the new expression.
  • Using De Morgan without switching ∧ and ∨.
  • Using = between propositions; the lecture uses ≡ for logical equivalence.
  • Distributing only one branch: p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r).

Stretch: NAND from a recent paper

The Fall 2025 Midterm defines p NAND q = ¬(p ∧ q). This is not a new mystery: expand NAND into familiar connectives, then use the same laws. For example, p NAND p ≡ ¬(p ∧ p) ≡ ¬p by idempotence. Keep this optional until the core laws feel secure.
