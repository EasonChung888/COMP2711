Build compound propositions

“Not”, “and”, and “or” have exact truth conditions in logic.

Day 12 of 615 minutes

Concrete goal

Translate and evaluate negation ¬, conjunction ∧, inclusive disjunction ∨, and exclusive or ⊕.

Connectives are truth-value machines

Give a connective the truth values of its inputs, and it returns one truth value. Ordinary “or” can be ambiguous; logical ∨ is inclusive, so it remains true when both inputs are true.

Formal lecture definitions

pq¬pp ∧ qp ∨ qp ⊕ q

  • ¬p reverses the truth value of p.
  • p ∧ q is true only when both parts are true.
  • p ∨ q is true when at least one part is true.
  • p ⊕ q is true when exactly one part is true.

Worked example 1: translate before evaluating

Let p be “The server is online” and q be “The database is reachable”. Suppose p = T and q = F.

  1. “The server is online and the database is not reachable” becomes p ∧ ¬q.
  2. Since q = F, negation gives ¬q = T.
  3. Now evaluate T ∧ T; conjunction gives T.

Likely error: applying ¬ to the whole sentence instead of only to q.

Worked example 2: inclusive versus exclusive

Suppose p = T and q = T.

  1. p ∨ q = T because at least one part is true.
  2. p ⊕ q = F because exclusive or requires exactly one true part.
  3. The two operators differ precisely in the T,T row.

Common mistakes

  • Reading ∨ as “one or the other, but not both”.
  • Calling p ∧ q true when only one conjunct is true.
  • Forgetting that negation acts only on the expression immediately following it unless parentheses enlarge its scope.

Two short checks

1. If p = T and q = F, what is ¬p ∨ q?

Hint

¬T = F, then use the F,F row for ∨.

2. When is p ⊕ q true?

Hint

The word “exclusive” excludes the row where both inputs are true.

Takeaway

∧ means both, ∨ means at least one, and ⊕ means exactly one.
