Lesson 3

Implication is a promise

An “if … then …” statement fails in exactly one case: its hypothesis happens but its conclusion does not.

Day 13 of 618 minutes

Concrete goal

Evaluate and translate p → q and p ↔ q, including “only if”, necessary conditions, and sufficient conditions.

Read p → q as a promise

The promise says, “Whenever p happens, q happens.” It is broken only when p = T and q = F. When p never happens, this particular promise has not been broken, so the conditional is true.

In p → q, p is the hypothesis and q the conclusion. Here p is sufficient for q, while q is necessary for p.

  • p only if q means p → q.
  • q if p means p → q.
  • p ↔ q means “p if and only if q” and is true when they match.

Worked example 1: necessary means right-hand side

Original wording, 2019 Midterm Problem 1(c): “To be windy it is necessary that it be cold.” Let w mean “It is windy” and c mean “It is cold”.

  1. The condition described as necessary is “it is cold”, so c must be the conclusion.
  2. The condition that requires it is “it is windy”, so w is the hypothesis.
  3. Therefore the translation is w → c.

Likely error: writing c → w merely because “cold” appears later in the English sentence.

Worked example 2: related statements are not interchangeable

Begin with p → q.

  1. Its converse is q → p.
  2. Its inverse is ¬p → ¬q.
  3. Its contrapositive is ¬q → ¬p.
  4. Only the contrapositive is guaranteed to be logically equivalent to the original implication.

Common mistakes

  • Reversing “p only if q”. The arrow is p → q.
  • Calling a conditional false whenever its hypothesis is false; all such rows are true.
  • Treating the converse as equivalent to the original conditional.
  • Reading ordinary conversational “if” as “if and only if”; the course keeps them distinct.
