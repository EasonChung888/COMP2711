About 17 minutes · Predicate inference

Move safely between quantified claims and named cases

Quantifier rules let us zoom in from “everyone” or “someone,” reason about a named object, and then zoom out again. The name you choose carries a logical promise.

← Lesson 11 Inference reference Lesson 13 →

Your concrete goal

You will use all four predicate inference rules, explain when a name must be arbitrary or fresh, and combine quantifier rules with propositional rules in a numbered derivation.

Plain-English intuition: four ways to change zoom

A universal statement is a rule for every object, so you may apply it to any chosen case. An existential statement promises at least one witness, but does not tell you which familiar object it is. In the other direction, a fact about an arbitrary case can support a universal claim, while a fact about any particular case can support an existential claim.

The four lecture rules

RuleFormMeaning and side condition
Universal Instantiation (UI)∀x P(x) ∴ P(c)Choose any domain element c. A fact about all objects applies to it.
Universal Generalization (UG)P(c) for arbitrary c ∴ ∀x P(x)c must be arbitrary: the proof must use no special fact about it.
Existential Instantiation (EI)∃x P(x) ∴ P(c) for some cIntroduce a fresh witness name. Do not silently identify it with a previously named object.
Existential Generalization (EG)P(c) ∴ ∃x P(x)One established example is enough to prove that an example exists.
Arbitrary is not the same as fresh. UG needs a representative chosen without special properties. EI needs a new label for an unknown witness. Confusing these promises can turn a false argument into an apparently valid one.

Worked example 1: a universal rule plus a named fact

Premises: everyone in the class who is a student has taken computer science, and Joseph is a student. Target: Joseph has taken computer science.

Let P(x) mean “x is a student in this class” and C(x) mean “x has taken computer science.”

  1. ∀x(P(x) → C(x)) Premise
  2. P(Joseph) → C(Joseph) 1, Universal Instantiation. “Everyone” includes Joseph.
  3. P(Joseph) Premise
  4. C(Joseph) 2, 3, Modus Ponens.

UI only specializes the quantifier; MP performs the propositional inference. Do not merge them into an unexplained leap.

Worked example 2: follow one existential witness

Premises: ∃x(P(x) ∧ ¬R(x)) and ∀x(P(x) → U(x)). Target: ∃x(U(x) ∧ ¬R(x)).

  1. ∃x(P(x) ∧ ¬R(x)) Premise
  2. P(a) ∧ ¬R(a) 1, Existential Instantiation for a fresh witness a.
  3. P(a) 2, Simplification
  4. ¬R(a) 2, Simplification
  5. ∀x(P(x) → U(x)) Premise
  6. P(a) → U(a) 5, Universal Instantiation using the same witness.
  7. U(a) 3, 6, Modus Ponens
  8. U(a) ∧ ¬R(a) 4, 7, Conjunction
  9. ∃x(U(x) ∧ ¬R(x)) 8, Existential Generalization. The final claim no longer exposes the temporary name.

This is the complete derivation from L03 pp. 17-18. Its shape also matches 2019 Midterm Problem 4 (8 marks).

Common mistakes

  • Existence to universality: ∃xP(x) does not imply ∀xP(x). The witness may be the only object with property P.
  • Reusing a familiar name in EI: from “someone passed,” you cannot infer that Joseph passed. Use a fresh symbol such as a.
  • Generalizing a special case: proving P(2) using the fact that 2 is even does not prove ∀xP(x).
  • Switching witnesses: from P(a) and Q(b), you cannot infer ∃x(P(x) ∧ Q(x)). The two facts may concern different objects.

Check 2. Mixed quantified derivation

Premises: ∀x(C(x) → S(x)) and ∃x(E(x) ∧ ¬S(x)). Target: ∃x(E(x) ∧ ¬C(x)).

Write a numbered proof. State where the witness is introduced and why the final existential generalization is permitted. Adapted from COMP2711 Fall 2025 Midterm, Problem 2(c), 5 marks.

Hint

Instantiate the existential premise with a fresh a. Instantiate the universal premise at the same a. Modus Tollens gives ¬C(a).

Worked answer - open only after trying
  1. ∃x(E(x) ∧ ¬S(x)) Premise
  2. E(a) ∧ ¬S(a) 1, EI for a fresh a
  3. E(a) 2, Simplification
  4. ¬S(a) 2, Simplification
  5. ∀x(C(x) → S(x)) Premise
  6. C(a) → S(a) 5, UI
  7. ¬C(a) 4, 6, Modus Tollens
  8. E(a) ∧ ¬C(a) 3, 7, Conjunction
  9. ∃x(E(x) ∧ ¬C(x)) 8, EG

Takeaway

UI chooses any case, EI introduces a fresh witness, UG requires an arbitrary case, and EG records that a proven example exists.
