Lesson 4

Classify every possible world

A truth table checks all assignments. A counterexample needs only one carefully chosen assignment.

Day 14 of 618 minutes

Concrete goal

Build truth-table rows, classify a compound proposition as a tautology, contradiction, or contingency, and disprove a universal claim with one counterexample.

One column tells the story

With two variables there are four possible assignments: TT, TF, FT, FF. Evaluate the main connective last. Then read only the final column: all T means tautology, all F means contradiction, and a mixture means contingency.

Formal lecture definitions

  • A tautology is true for every assignment.
  • A contradiction is false for every assignment.
  • A contingency is neither: its final column contains both truth values.
  • Two compound propositions are logically equivalent when they have the same truth value under every assignment.

Worked example 1: prove a tautology

Classify p ∨ ¬p.

p¬pp ∨ ¬p
TFT
FTT
  1. List both possible values of p.
  2. Negate p row by row.
  3. The final column is entirely T, so the expression is a tautology.

Worked example 2: disprove with one row

Adapted from 2019 Midterm Problem 3(a): Is ((p → q) ∧ ¬p) → ¬q a tautology?

  1. To make an implication false, make its hypothesis true and conclusion false.
  2. Choose p = F and q = T. Then p → q = T and ¬p = T.
  3. The whole expression becomes (T ∧ T) → F, which is F.
  4. This single counterexample proves the expression is not a tautology. Because other rows are true, it is a contingency.

Likely error: producing a row where the formula is true. A counterexample must make the claim being tested fail.

Common mistakes

  • Listing fewer than 2ⁿ assignments for n variables.
  • Evaluating the outer connective before its components.
  • Calling any formula with one true row a tautology.
  • Giving a counterexample without showing that the final expression is false.

Takeaway

All T: tautology. All F: contradiction. Mixed: contingency. One false row is enough to refute a tautology claim.
