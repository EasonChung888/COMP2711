A. Propositional logic · 4 points

1. [2 pts] Which expression is equivalent to ¬(p ↔ q)?

Hint - open after the timer

List the two cases in which the truth values of p and q do not match.

2. [2 pts] Without a truth table, determine whether (p ∨ q) → r and (p → r) ∧ (q → r) are logically equivalent. Give a law at each transformation, or give a counterexample if you think they are not.

Marking guide - open after submission

1 mark for the correct verdict; 1 mark for a valid law-by-law derivation. The expressions are equivalent because both simplify to (¬p ∧ ¬q) ∨ r.

B. Predicate logic · 5 points

3. [2 pts] Which is the fully simplified negation of ∀x(M(x) → ∃y(S(y) ∧ R(x,y)))?

Hint - open after the timer

The negation says: there is an M-object for which no suitable S-object is related.

4. [3 pts] The domain for x,z is all people and the domain for y is all Logic problems. Let Student(x), Beginner(x), and Solved(x,y) have their natural meanings. Translate: “Every student solved at least one Logic problem that no beginner solved.”

Marking guide - open after submission

1 mark for ∀x(Student(x) → ...); 1 mark for an existential problem ∃y solved by that same x; 1 mark for ∀z(Beginner(z) → ¬Solved(z,y)) with correct scope. One answer is ∀x(Student(x) → ∃y(Solved(x,y) ∧ ∀z(Beginner(z) → ¬Solved(z,y)))).

C. Inference · 6 points

5. [2 pts] From a → b and b → c, which rule derives a → c?

6. [4 pts] Give a numbered derivation of ¬c from these premises: (1) a → (b ∧ ¬c), (2) d → a, (3) d ∨ e, (4) ¬e. Cite a rule and earlier line number(s) for every new line.

Marking guide - open after submission

One mark per justified step: d by DS from (3),(4); a by MP from (2) and d; b ∧ ¬c by MP from (1) and a; ¬c by Simplification.

D. Proof technique · 5 points

7. [1 pt] What proof structure is required for “n is even if and only if 3n+5 is odd”?

8. [4 pts] Prove that, for every integer n, n is even if and only if 3n+5 is odd. Clearly label the two directions.

Marking guide - open after submission

2 marks forward: if n=2k, then 3n+5=6k+5=2(3k+2)+1, which is odd. 2 marks reverse: contrapositively, if n=2k+1 is odd, then 3n+5=6k+8=2(3k+4) is even; hence if 3n+5 is odd, n is even.

Weakest-domain remediation

Propositional logic refresher + two retest prompts

10-minute reset: rewrite implications first; move negations inward one symbol at a time; for non-equivalence, seek one assignment where truth values differ.

  1. Without a truth table, simplify ¬(p → (q ∨ r)) until negation touches variables only.
  2. Decide whether p → (q ∧ r) and (p → q) ∧ (p → r) are equivalent. Prove or give a counterexample.
Predicate logic refresher + two retest prompts

10-minute reset: restricted “every” uses implication; restricted “some” uses conjunction; crossing a negation swaps ∀/∃ and negates the body.

  1. Negate ∀x(A(x) → ∃y(B(y) ∧ T(x,y))) with negation symbols only before predicates.
  2. Translate: “Every tutor recommended a book that no first-year student read,” using clearly defined predicates.
Inference refresher + two retest prompts

10-minute reset: circle the target, identify a rule that can produce it, and write any required Simplification or equivalence line explicitly.

  1. Name the rule: x → y, ¬y, therefore ¬x.
  2. Derive t from m → (s ∨ t), n → m, n ∨ r, ¬r, and ¬s.
Proof-technique refresher + two retest prompts

10-minute reset: write the logical form; state the method; expand parity definitions; finish by naming the required property. An iff proof always needs two arrows.

  1. Which method gives the useful opening for “if 5n+4 is odd, then n is odd”? Write its first assumption.
  2. Prove that integer n is odd if and only if 5n+2 is odd.
