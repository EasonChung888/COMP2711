Lesson 1

Propositions or not?

Logic starts by deciding whether a sentence has one definite truth value.

Day 11 of 612 minutes

Concrete goal

Identify propositions, distinguish them from questions and open sentences, and name them with symbols such as p and q.

Start with a claim

A proposition makes a claim. The claim need not be correct; it only needs to be either true or false, but not both.

Proposition

“1 + 1 = 3.” It is false, but it is a definite claim.

Not a proposition

“Who has an iPad?” It is a question, not a true-or-false claim.

Formal lecture definition

A proposition is a declarative statement that is either true or false, but not both.

Its truth value is T if it is true and F if it is false. Lowercase letters p, q, r, … are propositional variables: short names for complete propositions.

Worked example 1: an open sentence

Is x² - 3x + 1 = 0 a proposition?

  1. Find the variable. The value of x has not been assigned.
  2. Test definiteness. The equation can be true for some values and false for others.
  3. Conclude. Before x is fixed, this is not a proposition.

Likely error: treating every mathematical-looking sentence as a proposition.

Worked example 2: naming claims

Let p be “Beijing is the capital of China” and q be “1 + 1 = 3”.

  1. p is a proposition with truth value T.
  2. q is also a proposition, with truth value F.
  3. The letters name whole claims; they do not themselves mean “true” and “false”.

Common mistakes

  • A false statement can still be a proposition.
  • Questions, commands, and unassigned open sentences are not propositions.
  • You need not know which truth value a proposition has; it only needs to have one.

Two short checks

1. Which sentence is a proposition?

Hint

A proposition declares something; it does not request an action or information.

2. What makes “x + 2 = 5” a proposition?

Hint

The truth value currently depends on an unspecified variable.

Takeaway

A proposition is a declarative claim with exactly one truth value.
