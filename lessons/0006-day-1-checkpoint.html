Score: 0/10 · Answer all eight questions.

Part A: Translation — 2 points

1. Let r, w, and c mean rainy, windy, and cold. Translate: “It is rainy only if it is windy and cold.”

Hint

What must be true whenever it is rainy?

2. Let u mean “the file uploads” and s mean “the work is submitted”. Translate: “Uploading is sufficient for submission.”

Hint

Read it as “if the file uploads, then …”.

Part B: Truth and classification — 2 points

3. If p = F and q = F, what is the truth value of p → q?

Hint

Did a false hypothesis make a promise that could be broken?

4. Classify p ↔ ¬p.

Hint

A biconditional is true only when both sides match.

Part C: Equivalence — 4 points

5. Which expression is logically equivalent to ¬(p → q)?

Hint

An implication is false exactly when its hypothesis is true and conclusion false.

6. What does ((p → ¬q) ∧ q) → ¬p simplify to?

Hint

p → ¬q ≡ ¬p ∨ ¬q, so conjoining with q removes the ¬q branch.

Part D: Counterexamples — 2 points

7. Which assignment disproves the claim that p → (p → q) is a tautology?

Hint

Make the outer implication false first.

8. Which assignment shows that p → (q → r) and (p → q) → r are not equivalent?

Hint

Try making the first outer implication automatically true by setting p = F.
