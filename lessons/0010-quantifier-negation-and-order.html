About 18 minutes · Negation and equivalence

Push negation inward without changing the claim

To negate a quantified statement, reverse each quantifier as the negation crosses it, then use the propositional laws you learned on Day 1.

Your concrete goal

You can negate nested quantified expressions until every ¬ sits immediately before a predicate, identify the two valid distribution laws, and reject invalid distribution or mixed-order swaps with a small counterexample.

Plain-English intuition: deny the guarantee

“Everyone passed” is false exactly when “someone did not pass” is true. “Someone passed” is false exactly when “everyone did not pass” is true.

¬∀x P(x) ≡ ∃x ¬P(x)

¬∃x P(x) ≡ ∀x ¬P(x)

Mechanical rule: each time ¬ crosses a quantifier, flip ∀ ↔ ∃. Keep pushing until negation touches only a predicate.

What distributes - and what does not

StatusStatementReason in a finite domain
Valid∀x(P(x) ∧ Q(x)) ≡ ∀xP(x) ∧ ∀xQ(x)Every object must pass both tests.
Valid∃x(P(x) ∨ Q(x)) ≡ ∃xP(x) ∨ ∃xQ(x)Some object passes at least one test.
Invalid∀x(P(x) ∨ Q(x)) ≢ ∀xP(x) ∨ ∀xQ(x)Different objects may pass different tests.
Invalid∃x(P(x) ∧ Q(x)) ≢ ∃xP(x) ∧ ∃xQ(x)The two witnesses may be different objects.

Quantifier order follows a related rule: same-type neighbors may swap, so ∀x∀y R(x,y) ≡ ∀y∀x R(x,y) and ∃x∃y R(x,y) ≡ ∃y∃x R(x,y). Mixed neighbors generally may not swap.

Worked example 1: negate a nested statement

Negate ∀x(E(x) → ∃y W(x,y)) so that negation immediately precedes predicates.

  1. ¬∀x(E(x) → ∃y W(x,y)) Start with the negation of the whole statement.
  2. ≡ ∃x ¬(E(x) → ∃y W(x,y)) Cross ∀x; flip it to ∃x.
  3. ≡ ∃x(E(x) ∧ ¬∃y W(x,y)) Use ¬(p → q) ≡ p ∧ ¬q.
  4. ≡ ∃x(E(x) ∧ ∀y ¬W(x,y)) Cross ∃y; flip it to ∀y.

In English: there is an x with property E for which no y is a witness.

Likely beginner error: writing ¬(p → q) as ¬p → ¬q. The correct negation is p ∧ ¬q.

Worked example 2: one two-object counterexample catches both bad distributions

Let the domain be {a,b}, with P(a)=T, P(b)=F and Q(a)=F, Q(b)=T.

  1. Each object satisfies at least one predicate, so ∀x(P(x) ∨ Q(x)) is true.
  2. Not every object satisfies P, and not every object satisfies Q. Thus ∀xP(x) ∨ ∀xQ(x) is false.
  3. A witness for P exists (a) and a witness for Q exists (b). Thus ∃xP(x) ∧ ∃xQ(x) is true.
  4. No single object satisfies both, so ∃x(P(x) ∧ Q(x)) is false.

A single counterexample is enough to disprove a claimed logical equivalence.

Order check: a stronger claim can imply a weaker one

If ∃x∀y R(x,y) is true, one fixed x works for every y. Therefore, for each particular y, that same x is available, so ∀y∃x R(x,y) is true.

∃x∀y R(x,y) → ∀y∃x R(x,y)

The converse is not guaranteed: different values of y may require different choices of x. This is the key distinction tested in 2024 Spring Midterm, Problem 3.

Common mistakes

  • Moving ¬ without flipping the quantifier: every crossed ∀ becomes ∃, and vice versa.
  • Stopping too early: “negation immediately precedes predicates” means no ¬ may remain before a quantifier, connective, or parenthesized compound.
  • Distributing by visual symmetry: only ∀ over ∧ and ∃ over ∨ work in both directions.
  • Swapping ∀ and ∃: mixed order changes which witness may depend on which value.

Two short checks

Check 1

Which is the negation of ∀x(A(x) → ∃y B(x,y)) with negations only before predicates?

Hint

Use ¬∀xS ≡ ∃x¬S and ¬(A → B) ≡ A ∧ ¬B.

Check 2

Which equivalence is valid over every common nonempty domain?

Hint

Over a finite domain, ∀ expands to a large AND and ∃ expands to a large OR.

Stretch only: null quantification

If x is not free in A, then a quantifier over x can move across a connective involving A. For example:

∀x(A ∧ P(x)) ≡ A ∧ ∀xP(x)

The condition is essential: if x occurs freely in A, moving the quantifier may capture a variable and change the statement. This topic is optional for the two-day core.

Takeaway

Negation flips every crossed quantifier; valid distribution depends on matching ∀ with ∧ or ∃ with ∨.
