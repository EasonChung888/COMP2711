# COMP2711 Logic 与 Sets and Functions 课程设计

## 已批准的目标

现有 `courses/l2-5` 是 COMP2711 网站根目录。总首页按 Logic、Sets and Functions、Counting 排列模块。Logic 收纳 L1.1、L1.2、L1.3；Sets and Functions 收纳 L1.4；Counting 及其入口现有的 L1.5 标记保持原样。四份 `/Users/easonzhong/Downloads/L1.{1,2,3,4}.pdf` 是本次唯一新课件来源，分别为 47、53、45、44 页。描述性章节副标题在处理各 PDF 第 1 页后依实际标题确定。

## 页面与数据

沿用静态 HTML、现有 CSS、KaTeX、`file://` 离线访问。网站根目录新增 `logic.html` 和 `sets-and-functions.html`；四章位于 `chapters/l1-1` 至 `chapters/l1-4`，每章分别保存源 PDF、原页图、原文回答、单页 HTML、主题课、章节目录、页码索引、清单、真实事件日志和练习快照。新课程共用现有渲染与样式，不复制旧 Logic 两天网站或 Counting 的讲解内容。

既有 Counting URL、题目与存储键保留。每个新章节使用 `comp2711:l1-N:` 命名空间及稳定主题课 ID；总首页和模块页按完整键汇总进度。全站继续学习位置单独保存，同时兼容现有 `comp2711:l2-5:lastLesson`。每课只在所有讲解及练习之后显示一次“我已学完这课”，勾选、取消和草稿均立即保存。

## 内容生产

先把四个章节的目录与单页显示通道接入网站。按 L1.1 → L1.2 → L1.3 → L1.4、各 PDF 原页码顺序处理。每次仅提取、渲染并查看当前一页，提示词固定为「解释一下」；本对话主 AI 直接写出完整中文讲解，保留英文术语和数学符号。原文独立保存并计算 SHA-256，立即生成可阅读的单页网站，验证一致并追加成功事件后才能看下一页。标题、过渡及总结页同样处理；失败时停留本页，从首个未完成页恢复，已有完整回答直接复用入站。

全部 189 页完成后，依据已保存讲解按知识主题分课，前置概念先于应用，课内维持原页序，只改变归属而不改写回答。此后才从现有知识库挑选每课约三道匹配、答案独立核实的原题，保留原文、图示、题号和出处；题少用实际数量，零题明确说明。答案折叠展示。源内容有错误时另列勘误，不修改原回答。

## 验收

校验四源哈希和 189 页完整覆盖、每页原图/原文/HTML/哈希、真实日志串行顺序、主题唯一归属、练习匹配与来源、各层导航及所有本地资源。实测桌面和窄屏的原页图、公式、答案展开、草稿、选择题选中即提交、整课完成/取消与刷新恢复、继续学习和 Counting 原进度。报告实际结果与任何未解决问题。
