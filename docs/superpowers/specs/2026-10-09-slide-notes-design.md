# 每页课件笔记

为所有 `.slide-explanation[data-slide]` 的讲解正文增加可输入的笔记。沿用现有配色、字体和本地静态网站架构。桌面采用正文与笔记两栏，900px 以下依次显示正文和笔记；笔记在长正文旁保持可见，但不超出当前页的讲解范围。

使用共用 site.js 渐进增强页面，不重写讲解、不重新生成课程 HTML。保留 response-body 本身及其中全部内容。笔记按 body 的章节 storagePrefix 与规范化原页码存储，键为 `${prefix}slide-note:${Number(data-slide)}`，课程页与独立课件页复用同一键。

提供原生 textarea、明确的页码标签、本地保存说明及保存状态。每次 input 同步写入 localStorage，避免导航前尚未保存；清空内容删除对应键。读取或写入失败时保留当前输入并提示复制备份。恢复浏览器后退缓存和其他窗口存储更新时刷新未编辑的笔记，失败的本地草稿不被覆盖。

不引入服务、第三方依赖、富文本或云端同步。现有解题草稿、整课进度、公式和选择题即时提交继续工作。打印时隐藏编辑区，恢复完整正文宽度。

验收：覆盖全部课件讲解入口；离线 file:// 输入与刷新恢复；课程页与单页共享；不同页和章节隔离；清空恢复；读写错误；桌面两栏与窄屏无水平溢出；讲解内容保持不变。
