# Functions - 函数

## Definition｜定义

A function assigns exactly one codomain value to each domain element. 从 $A$ 到 $B$ 的函数由定义域每个元素的像唯一确定。

## Recognition Cues｜识别线索

For a function $S_k\to S_n$, begin with $k$ image choices; equality restrictions link named image values. 题目给出 $f(i)$ 的不等式时，先选择受限制最强的值。

## Worked-use note｜使用提醒

Separate restrictions on pairs of images from restrictions on every image; $f(1)\ne f(2)$ says nothing about $f(3)$.
