# Countability - 可数性

## Definition｜定义

A set is countably infinite if it admits a bijection with the positive integers. Finite and countably infinite sets are countable; the real numbers are uncountable. 可数无限集可以排成没有遗漏的一列。无限并不自动意味着不可数，正整数与整数、整数对都可数。

## Enumeration｜枚举

Enumerate positive integer pairs along diagonals of fixed sum: $(1,1)$; $(1,2),(2,1)$; $(1,3),(2,2),(3,1)$; and so on. Each pair has finite coordinate sum and therefore appears after finitely many entries. 按坐标和递增排列可以避免第一行永远列不完、第二行从未开始的错误。

## Removing a countable subset｜去掉可数子集

If an uncountable set became countable after deleting a countable subset, putting that subset back would make the original set a union of two countable sets, hence countable, a contradiction. 因此从实数中去掉正整数后仍不可数；但两个不可数集合的差可以为空、可数无限或不可数。
