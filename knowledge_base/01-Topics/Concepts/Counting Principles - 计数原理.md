# Counting Principles - 计数原理

## Definition｜定义

The product rule multiplies sequential independent choices; the sum rule adds disjoint alternatives. 乘法原理处理连续选择，分类互斥时才可使用加法原理。

## Recognition Cues｜识别线索

Look for a construction performed in stages, or wording such as ‘either … or …’. 识别每一步的可选数和不同方案是否会重叠。

## Worked-use note｜使用提醒

In a case split, state why every valid object occurs in one case and no object occurs twice.

The pigeonhole principle says distributing more than $m(r-1)$ objects among $m$ boxes forces some box to contain at least $r$. To prove the threshold is minimal, give $r-1$ objects to each box. 抽屉原理的阈值证明包含两面：超过总容量必有一组达标，而刚好填满每组上限说明少一个仍可能不达标。
