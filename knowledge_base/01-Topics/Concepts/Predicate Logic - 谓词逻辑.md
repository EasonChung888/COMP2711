# Predicate Logic - 谓词逻辑

## Definition｜定义

Predicates express properties of quantified objects; $\forall$ asserts every object and $\exists$ supplies one witness. 谓词逻辑中量词的作用域和同一见证对象决定语义。

## Recognition Cues｜识别线索

‘All … are …’ normally becomes a universal implication; ‘some … with …’ becomes one existential conjunction. 量词前后出现否定时必须检查作用域。

## Worked-use note｜使用提醒

Keep all properties of one existential witness on the same variable; use $\neg\exists x P(x)\equiv\forall x\neg P(x)$ only with the quantifier properly moved.
