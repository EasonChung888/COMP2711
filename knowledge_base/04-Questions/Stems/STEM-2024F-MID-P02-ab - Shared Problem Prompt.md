# STEM-2024F-MID-P02-ab - Shared Problem Prompt

## Shared printed wording

Consider the following predicates:
$Prime(x)$: $x$ is prime
$Even(x)$: $x$ is even
The domain is all natural numbers $(0,1,2,\ldots)$.
$$\forall x((Even(x)\land x>2)\to\exists y\exists z(Prime(y)\land Prime(z)\land(y+z=x)))$$
