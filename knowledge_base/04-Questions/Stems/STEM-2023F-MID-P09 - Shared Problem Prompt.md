# STEM-2023F-MID-P09 - Shared Problem Prompt

## Shared printed wording

Each time, a robot can move $X$ cm to the right (negative $X$ means the robot move to the left). $X$ is a discrete random variable taking values from $\mathbb N$ with the following PMF (probability mass function),
$$p(X=i)=\begin{cases}\frac23&\text{if }i=1,\\\frac13&\text{if }i=-1,\\0&\text{otherwise.}\end{cases}$$

For (d): This robot is standing at position 0. It stops once it reaches to position $+1$ cm. Before stopping, the robot moves $T$ times where $T$ is a random variable.
