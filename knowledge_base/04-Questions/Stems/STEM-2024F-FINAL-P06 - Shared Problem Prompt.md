# STEM-2024F-FINAL-P06 - Shared Problem Prompt

## Shared printed wording

Assume that $a,b$ are integers and $p$ is a prime number of form $4k+3$ (with an integer $k$). As an example, 19 is a prime of this form while 17 is not of this form.
Assume that $p\mid a^2+b^2$.
