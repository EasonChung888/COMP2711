# STEM-2018-FINAL-P04-c - Shared Problem Prompt

## Shared printed wording

For this question, no proof is required. Fill in the following recursive definition so that $S$ is the set of complete graphs.

Recursive step: Suppose that $G=(V,E)$ is in $S$, where $V=\{v_1,v_2,\ldots,v_n\}$. Then $G'=(V',E')$ is in $S$, where $V'=\{v_1,v_2,\ldots,v_n,v_{n+1}\}$.
