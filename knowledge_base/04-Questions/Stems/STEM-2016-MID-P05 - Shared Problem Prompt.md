# STEM-2016-MID-P05 - Shared Problem Prompt

## Shared printed wording

There are $n$ dots painted on a paper. A kid draws some line segments on the paper and each line segment connects exactly two dots as the two end-points of this line segment. For example, the following figure shows 3 line segments and 6 dots.

Note that if one line segment (connecting two dots) is an extension of another line segment (connecting two dots where one of them is the dot connected by the previous line segment mentioned), we will still refer them as two separate line segments (not one line segment). For example, the following figure shows 3 line segments and 6 dots.

We say that the $n$ dots are all connected if for every pair of two dots $x$ and $y$, there exists a sequence of line segments, namely $(d_1,d_2),(d_2,d_3),(d_3,d_4),\ldots,(d_{l-1},d_l)$ where $d_i$ is a dot for $i\in[1,l]$, such that $d_1=x$ and $d_l=y$. For example, the following figure shows that the 6 dots are all connected but the above 2 figures shows that 6 dots are not all connected.
