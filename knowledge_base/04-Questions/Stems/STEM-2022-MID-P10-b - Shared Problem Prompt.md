# STEM-2022-MID-P10-b - Shared Problem Prompt

## Shared printed wording

The following algorithm finds an element $x$ in a list of $n$ integers:

~~~text
for i ← 1 to n
    if x = a_i then return i
return “not found”.
~~~

Determine the best-case and worst-case running time using the $\Theta$ notation. No justification is needed.
