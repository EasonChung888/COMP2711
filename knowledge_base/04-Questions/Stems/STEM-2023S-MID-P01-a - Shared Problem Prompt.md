# STEM-2023S-MID-P01-a - Shared Problem Prompt

## Shared printed wording

Let

1. $r$: It rains.
2. $f$: It is foggy.
3. $s$: The sailing race will be held.
4. $l$: The life saving demonstration will go on.
5. $t$: The trophy will be awarded.

Hypotheses (the printed premises, retained for the translation and inference atoms):

1. If it does not rain or if it is not foggy, then the sailing race will be held and the lifesaving demonstration will go on.
2. If the sailing race is held, then the trophy will be awarded.
3. The trophy was not awarded.
