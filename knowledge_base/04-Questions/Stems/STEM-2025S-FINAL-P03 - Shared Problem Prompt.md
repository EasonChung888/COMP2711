# STEM-2025S-FINAL-P03 - Shared Problem Prompt

## Shared printed wording

For a positive integer $p$, define the positive integer $n$ to be $p$-safe if $n$ differs in absolute value by more than 2 from all multiples of $p$. For example, the set of 10-safe numbers are $3,4,5,6,7,13,14,15,16,17,\cdots$.
