# STEM-2022-MID-P10-a - Shared Problem Prompt

## Shared printed wording

Determine the best-case and worst-case running time of the following algorithms using the $\Theta$ notation. No justification is needed.

The following algorithm finds the maximum of a sequence $\{a_1,a_2,\ldots,a_n\}$ of $n$ integers:

~~~text
max ← a_1
for i ← 2 to n
    if max < a_i then max ← a_i
return max
~~~
