# STEM-2017-FINAL-P10 - Shared Problem Prompt

## Shared printed wording

Let S be the subset of the set of ordered pairs of integers defined recursively by:

Basis step: $(0,0)\in S$

Recursive step: If $(a,b)\in S$, then $(a,b+1)\in S$, $(a+1,b+1)\in S$, and $(a+2,b+1)\in S$.
