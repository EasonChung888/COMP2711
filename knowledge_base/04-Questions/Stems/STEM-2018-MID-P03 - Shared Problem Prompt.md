# STEM-2018-MID-P03 - Shared Problem Prompt

## Shared printed wording

Consider the set $S=\{1,2,\ldots,2n\}$, and subsets $P=\{p_1,p_2,\ldots,p_m\}\subseteq S$ such that they satisfy the following criterion:

$\forall p_i\in P\forall p_j\in P(i\ne j\to p_i\nmid p_j)$

In the above, $p_i\nmid p_j$ means $p_j$ is not divisible by $p_i$.
