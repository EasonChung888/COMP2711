# STEM-2021-FINAL1-P06 - Shared Problem Prompt

## Shared printed wording

A string is called E-String if the string consists of only digits in $\{0,2,4,7,8,9\}$ and the sum of the digits is even. E.g. “079” is an E-String because $0+7+9=16$ is even. “708” is not an E-String because $7+0+8=15$ is odd. “107” is not an E-String because the digit 1 is not allowed. The empty string is also considered an E-string.
