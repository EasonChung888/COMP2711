# STEM-2015-FINAL-P05 - Shared Problem Prompt

## Shared printed wording

Let $p$ be a prime number. For any two integers $x$ and $y$ from $\mathbb Z_p$, if
$$x=y^2\bmod p,$$
then we say that $x$ is a quadratic residue mod $p$, and that $y$ is a square root of $x$ mod $p$.
