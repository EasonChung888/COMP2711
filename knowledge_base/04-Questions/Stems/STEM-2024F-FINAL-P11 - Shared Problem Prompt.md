# STEM-2024F-FINAL-P11 - Shared Problem Prompt

## Shared printed wording

The complement or inverse of a graph G is a graph H on the same vertices such that two distinct vertices of H are adjacent if and only if they are not adjacent in G.
A self-complementary graph is a graph which is isomorphic to its complement. As an example, the following graph is self-complementary.

![[knowledge_base/06-Audit/figures/task8-2024F-FINAL-P11.png]]

Assume a graph G is a self-complementary graph with n nodes. Consider H as its complement. Assume S to be the sum of all the nodes degrees in G.
