# STEM-2023S-MID-P08 - Shared Problem Prompt

## Shared printed wording

For each pair of expressions $(A,B)$ below, indicate whether $A$ is $O$, $\Omega$, or $\Theta$ of $B$. Note that zero, one, or more of these relations may hold for a given pair. List all correct ones. It often happens that some students will get the directions wrong, so please write out the relation in full, i.e., $A=O(B)$, $A=\Omega(B)$, or $A=\Theta(B)$ and not just $O(B)$, $\Omega(B)$, or $\Theta(B)$, omitting the $A$.
