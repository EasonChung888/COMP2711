# STEM-2025F-FINAL-P04 - Shared Problem Prompt

## Shared printed wording

Assume there are 4 teachers (T), 5 engineers (E), 6 doctors (D) and 7 students (S). These $4+5+6+7=22$ people want to stand in a single queue (a line with a well-defined front/head and back/end). Every individual is a distinct person (i.e., they are all different people)
Determine the number of ways to arrange them in the queue for each of the following conditions. No argument is needed. There is no need to calculate the exact numerical answer.
You are not allowed write the answer in any form of summation.
