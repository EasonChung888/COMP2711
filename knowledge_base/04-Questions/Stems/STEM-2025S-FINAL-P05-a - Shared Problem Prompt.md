# STEM-2025S-FINAL-P05-a - Shared Problem Prompt

## Shared printed wording

(a) [6 pts, 2 each] For each pair of expressions $(A,B)$, indicate whether $A$ is $O,\Omega,\Theta$, of $B$. Note that zero, one, or more of these relations may hold for a given pair. List all applicable relations. No explanation is needed.

Examples: (a) for $A=n,B=2n$, all $O,\Omega$ and $\Theta$ are correct; (b) for $A=n,B=n^2$, only $O$ is correct.
