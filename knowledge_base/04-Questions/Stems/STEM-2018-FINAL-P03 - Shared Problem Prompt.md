# STEM-2018-FINAL-P03 - Shared Problem Prompt

## Shared printed wording

$S$, a set of integers, is recursively defined as follows:

Basis: 4914 and 3588 are in $S$.

Recursive step: If $x,y\in S$, then $x-y\in S$.

(Note that $x$ and $y$ may be the same.)
