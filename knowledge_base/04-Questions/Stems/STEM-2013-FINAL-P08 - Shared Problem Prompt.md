# STEM-2013-FINAL-P08 - Shared Problem Prompt

## Shared printed wording

Consider a function $T(n)$ defined on integers $n$ that are powers of 2. Suppose
$$T(1)=1,\qquad T(n)=3T(n/2)+n^2.$$
