# STEM-2014-MID-P04 - Shared Problem Prompt

## Shared printed wording

An anagram is a distinct ordering of the letters. For example, the word “eat” has six anagrams “eat”, “eta”, “ate”, “aet”, “tea” and “tae”, while the word “too” has only three anagrams “too”, “oto” and “oot”.
