# STEM-2017-FINAL-P03 - Shared Problem Prompt

## Shared printed wording

For each of the following parts, find the “best” big-$O$ notation to describe the complexity of the algorithm. Choose your answers from the following:

$O(1),O(\log n),O(n),O(n\log n),O(n^2),O(n^3),\ldots,O(2^n),O(n!)$

Assume that the amount of time to print any string is a constant, i.e. $O(1)$.
