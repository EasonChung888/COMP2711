# STEM-2024F-FINAL-P09-a - Shared Problem Prompt

## Shared printed wording

For each pair of expressions $(A,B)$, indicate whether A is $O,\Omega,\Theta$, of B. Note that zero, one, or more of these relations may hold for a given pair. List all applicable relations.
No explanation is needed.
As an example for $A=n,B=2n$, all $O,\Omega$ and $\Theta$ are correct.
