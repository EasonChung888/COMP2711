# COMP2711 2026-27 Syllabus Baseline

This versioned baseline reproduces the content taxonomy and Rosen references in the official [HKUST COMP2711 Fall 2026-27 syllabus](https://seng.hkust.edu.hk/sites/default/files/IMCE/UG/Course%20Syllabus/Fall_2026-2027/COMP2711_Fall%202026-27.pdf). The official table cites *Discrete Mathematics and Its Applications*, Rosen, 8th edition.

## Admission Rule

An atomic past-paper subquestion is admitted to the main knowledge graph only when its assessed knowledge and **all core concepts needed for a normal solution** map to a Topic and Subtopic in this baseline. Incidental context outside the syllabus does not exclude a question when the required solution concepts remain in scope. Any item that cannot be mapped conclusively is recorded as `needs-review`; an item requiring content outside this baseline is recorded as `out-of-scope`. Neither receives a Question note until admitted.
